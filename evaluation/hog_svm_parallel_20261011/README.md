# HOG–SVM 独立任务线：2026-10-11 增强诊断

## 决策

保持旧 HOG324 基线权重。水平镜像、镜像加小平移均未通过预先登记的行人/车辆不退步门禁，不进入 RTL。对照组复现成功；它没有改善准确率，因此不作为新模型。

本批与 CNN 并行，只新增 HOG 诊断入口、测试和实验产物。生产 RTL、历史模型、人工原始标注、test/blind 均未修改或用于训练。本地分支为 `work/roadyolo`；用户授权阶段验证后提交并推送，远程 `origin` 尚未配置，当前只能本地提交。

## 固定实验

预注册文件：`experiment.json`，SHA-256 `4dffbfee4f550702f622e623daa66a9c4ec28a3062328438a42461c4c29e6963`。

- 训练仅用已审计 VIRAT `000201/000206` 的 360 个 ROI：160 ped、200 vehicle。
- 固定三种拟合：原样本对照；原样本加水平镜像；原样本/镜像各加 0、左右/上下 2 像素平移。平移在原 32×32 ROI 内复制边界，不产生新的源画面信息。完成首次实验后因复跑入口修复，按完全相同三方案验证重放一次；两次模型、预测和数值 trace 完全一致，没有追加参数选择。
- 训练行数分别 360、720、3600；每个原始 ROI 的总样本权重仍为 1。增强副本不算独立目标。scaler 只在各组训练数据上拟合；固定 LinearSVC C=1、balanced、seed=20260927；推理仍使用原 HOG324 和零分数二分类边界。
- 评估分别为公开 val69、已确认近距离视频真值框 B57、同一批目标的匹配候选框 C14。B/C 不合并为独立样本；端到端分母保持 57，包含 43 次未匹配目标观测。
- 不扫描新参数、不重选阈值；没有 invalid 样本，误接受率仍未知。

## 验证与数值边界

- 对照组全部 500 个输入视图（含 train360）的浮点/定点标签均重现旧模型；最大浮点分数差约 1.85e-13，量化权重和偏置完全一致。
- 每组在 val69/B57/C14 分别为零浮点/量化标签差异，未发生每类 recall 损失。按组计算，避免 B/C 配对视图稀释量化错误率。
- 已检查 train/evaluation 的 scene、源片族、来源哈希和 ROI 像素隔离，增强后无跨集合像素重复或跨类别冲突；原样本增强权重保持不变。
- 当前三个模型对合法特征范围 0..4096、实际导出权重的保守部分和界需 signed34；若允许完整 signed16 权重范围则需 signed37；再允许 13bit 特征端口满幅 0..8191 则需 signed38。观测数据只需 signed30，不能用观测界替代最坏界。尚未冻结硬件数值格式。
- 保存 324 项权重乘积和 bias-first 部分和到本地 NPZ，并绑定哈希；源码、模型、数据、工具版本见 `augmentation_v1_verified/report.json`。NPZ 属 Git 排除的本地数值产物，代码/清单/JSON/CSV 进入 Git。
- 协调代理复跑：`python tests/test_hog_svm_augmentation.py` 五项通过；`python tools/hog_svm_augmentation_diagnostic.py self-test` 通过。额外只读复核见 `verification.json`。

这里的 HOG324 仍由浮点 OpenCV 提取，验证的是量化线性层，不是完整整数 HOG 或 RTL 逐级一致性。没有本次新 RTL、资源、时序或板级通过结论。

权威运行目录为 `augmentation_v1_verified/`。原 `augmentation_v1/` 留作先前运行记录：其报告的源码哈希曾被后处理更新，不能作为当前源码执行证据。随后发现新复跑入口的函数返回位置错误，已修复并加入合成训练/折叠分数检查；新目录由修复后的完整入口实际重放生成，报告明确记录两次执行及逐值一致结果。当前不保留可改写旧收据的后处理入口。
