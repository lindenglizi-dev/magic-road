# Guarded final-four development decision

状态：Python开发扫描和两批人工审核已收口；`fill_only_T100` 仍是实验候选，正式RTL门禁保持关闭。

架构领导者确定的本轮规则保护原始面积top-4主候选，小候选仅填补空槽；实验分支允许在严格条件下每帧最多替换一次末位主候选。内部池最多8项，最终输出最多4项。

四个开发窗口共扫描24组替换配置。每组都在`VIRAT_S_000206_07_001501_001600`产生vehicle baseline覆盖损失，因此未通过逐窗口vehicle IoU≥0.25和0.5均`lost=0`的开发门禁。替换分支本轮否决，不能用ped净增抵消车辆损失。

`fill_only_T90/T100/T110`均保留全部主候选，并通过所有窗口的vehicle零损失门禁。三者差异很小；T90相对T100/T110在全部11132条ped标注行中，IoU≥0.25只多1条、IoU≥0.1只多2条，IoU≥0.5相同，而且差异来自长训练窗口。领导决策因此选择扫描区间中点`fill_only_T100`进入人工审核，以T90/T110作为敏感性对照。该选择不是阈值冻结。

T100的ped IoU≥0.25逐窗口annotation-row geometry coverage净增为`+47/+2/+105/+13`。这些是时间相关的几何覆盖行数，不是独立目标数、检测召回或分类性能。

配对审核批次将579个实际填空候选确定性合并为54个唯一时间组：45个稳定组、9个阈值敏感组。目标60组缺6组，全部现有组均入审，未复制相邻帧。原始审核清单和图片位于`evaluation/candidate_reviews/guarded_fill_only_T100_paired_review/`，规范化收据位于`evaluation/candidate_reviews/finalized_20260927/`。

审核后，54组中语义目标33组、背景碎片21组，语义目标比例61.1%；语义目标中可用裁剪24/33=72.7%。它通过预先设定的新增目标比例60%门槛，但没有达到可用裁剪80%门槛，因此本轮不冻结候选语义。`internal8_to4`的120项只保留作失败类型分析；3项不确定记录排除在指标外，7项背景备注缺失保留为开放审核缺口。

T100仅在本轮HOG诊断中以`experiment_roi_contract_v1`冻结。若透视阈值、扩框、margin、NMS或代表帧规则改变，必须重建ROI并重跑全部诊断。下一步补充未参与规则制定的新验证场景和可用完整裁剪；正式RTL、训练导入和blind test继续关闭。
