# 标签来源更正与本轮优化边界

本文件补充历史收据，不覆盖已哈希的原始文件。自本次优化开始，下游必须结合本文件判断证据等级。

- `intersection_2415171_review60_v1/human_labels.csv` 文件名不准确：60条标签由 py_reference / verify / review 智能体视觉初标，并非用户或独立自然人审核。`reviewed_manifest.csv` 与 `review_report.json` 中的 10 ped / 3 vehicle / 47 invalid 和对应分类比例仅是 AI 初标诊断，不能用于人工验收、模型冻结或训练导入。
- 这些视觉审核页面中可见分类器预测，不能把“取样过程未使用模型分数”扩写成“标签审核对预测完全盲法”。取样过程和标签生成过程是两回事。
- 截断人体在历史初标中有时被改判 invalid，需把 `semantic_class` 与 `crop_usable` 分开复核，不能通过把难识别的行人排出分母提高召回。
- `evaluation/candidates/virat_000201_60f` 的88条标签同样需要按实际 reviewer 核对。当前核查为66条官方标注重叠辅助、22条 Codex 视觉判断；没有确认收据时，仅能用于显式标注的弱标签探索。
- 同次核查确认，历史验证CCL70条为6条官方标注重叠辅助与64条Codex视觉初标，亦非人工确认gold。其历史分组正确数可保留复现，但证据等级同样降为参考诊断；这不否定用户实际填写过的其他独立审核CSV。
- 官方对象标注生成的 GT ROI 与算法辅助 CCL 标签分别报告。验证样本不得导入训练。
- 独立帧标注包 `intersection_2415171_target32_v2/annotate.html` 从空标签开始，分类分数隐藏；只有填写审核者、实际日期、完成32帧且明确确认后，配对评估器才接受为人工完整帧标签。
- Wilson 区间如出现在旧报告中，只是按独立二项样本的描述值，未修正轨迹相关性与分层抽样，不能证明跨场景提升。
- 双时间尺度背景与20/25个百分点下降条件均是未验证的建议，不是已冻结算法或验收门槛。

本轮可执行：在训练/验证场景隔离下，固定参数比较预处理，以及明确标注弱监督来源的分类试验。等待人工确认的工作：新路口完整框与CCL框配对、实际候选人工评估和最终模型选择。正式RTL接入保持关闭。
