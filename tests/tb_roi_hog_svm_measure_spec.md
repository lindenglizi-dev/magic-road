# 四对象 ROI/HOG/SVM 测量夹具

用途：验证现有三个算法级能够处理一帧四个对象，记录周期；不进入正式 TD 工程。

- 无外部端口，100 MHz 时钟，低有效复位；在负沿释放复位、发送输入。
- 帧号 7，四个有效框均为分析坐标 `[10,20]..[25,27]`。
- 灰度存储模型返回 `x XOR y`，同步一拍响应；不包含物理 ERAM、CDC 或采集。
- 使用真实 `roi_frame_reader → hog_sobel_gradient → hog_cell_histogram → hog_linear_svm`。
- 权重固定为 1，偏置为 0。每框 Python 黄金分数 14176，不是训练模型。
- 验证 4096 个像素、256 个特征、4 个按序分类结果及一次 bank 释放；任何协议错误失败。
- 最后灰度响应排空后可释放；最后 SVM 结果晚于释放，测量程序单独记录这两个时刻。
- 超时 1 ms 结束失败，避免仿真无界等待。

时序示意（事件间距离以测量 JSON 为准）：

```text

result_valid        __________|‾|____|‾|____|‾|________|‾|_
```

该夹具的功能证据为 Icarus 编译/执行、黄金分数及计数断言；未执行 strict formatter/style 全门禁或综合，不作为硬件时序证据。
