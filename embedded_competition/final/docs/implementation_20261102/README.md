# 布局布线与时序结果

本目录对应 2026-11-02 完成的 Tang Dynasty 6.2.168116 构建，器件为 PH1P35MDG324、速度等级 3。

- `reports`：资源、慢快双角时序、双视图签核结果及实际布局布线参数。
- `screenshots`：TD 界面截图。正文可选布局密度、物理资源、全局时序和分析设置四张。
- `native_checks`：时钟、引脚及上电复位检查结果摘要，保留原记录校验值。
- `host_offline_receipt.json`：上位机离线回归结果及源文件校验值。
- `report_provenance.json`：公开报告与原始工具输出的校验对应关系。

公开文本报告仅将构建电脑的绝对路径替换为 `<build_root>`，统计值、时钟、约束内容及路径延迟保持原值。原始输出在发布归档中保留。

08 为布局密度分布图，颜色按右侧图例解释；09 为局部布线资源结构，不能标为某条信号的实际走线或拥塞图。setup 裕量为 1 ps，结论限于本次构建的检查结果。

位流、数据库和发布信息见本目录 `release.json`。数据库仅随比赛包提供，查看方式见 [构建说明](../构建说明.md)。
