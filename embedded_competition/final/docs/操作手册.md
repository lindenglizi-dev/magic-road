# 操作手册

先安装环境，运行根目录启动入口。开发板接供电、摄像头、HDMI和千兆网线。FPGA默认192.168.137.2，电脑有线网卡配置为同网段，例如192.168.137.1/24。UDP视频端口6001，控制端口6002。

## 应用与显示切换

算法列表保留原布局：0原图、1白平衡、2灰度二值化、3中值滤波、4边缘检测、5锐化、6伽马矫正、7对比度、8亮度、9图像编辑；另有10小球检测/计数。选择后点“应用算法”，等待回读与完整帧确认。

- 选择0～9进入算法展示，小球检测暂停，历史累计数保留；返回10后重新确认目标，不补计展示期间的过线。
- 左侧底部“切换到原图/切换到小球识别”是另一种显示切换：在应用10内切到原图，后台检测和计数继续，界面暂时隐藏小球结果；切回后恢复结果显示。
- 从0～9点击底部“切换到小球识别”，上位机会依次切应用10和检测视图。

因此，列表里的“0原图展示”和底部按钮的“原图（后台继续计数）”作用不同。

## 小球参数与计数

进入应用10的检测视图后，在03区选择良品颜色（单色或红黄绿全部）、良品形状、严格颜色阈值、框/计数线和ROI、尺寸、面积等参数，再点“应用检测参数”。等待板端已应用版本回读，不能只看输入框数值。修改参数会开始新的一批计数。

三色合计最多跟踪4个目标。选定颜色中，满足形状与尺寸条件的目标为良品，不满足者为次品；待确认目标不计数。目标从左向右越线后，同一目标计一次；静止目标的框数不等于累计计数。“清零计数与轨迹”由上位机提交。

KEY1按下切换暂停/继续计数，识别与画框继续。KEY2按下切换颜色掩膜显示，**不切换红黄绿检测选择**。两键均无长按曝光/增益切档，长时间保持不会连续触发。人脸及独立TRACK模式未启用。

调色与切换都等待实际显示代次的完整帧。PC图片上传/PC Image输入尚未启用；本版本使用板载摄像头。上位机可保存当前完整视频帧、查看结果JSON及按当前检测视图记录结果。
