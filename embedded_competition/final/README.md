# FPGA 多算法视觉处理与彩球分检

基于安路 PH1P35 的实时摄像头视频处理系统，支持多算法显示、彩球识别计数和千兆以太网上位机。

## 功能

- 模式 0～9：原图、白平衡、灰度二值化、中值、边缘、锐化、Gamma、对比度、亮度、图像编辑。
- 模式 10：红、黄、绿彩球检测与分类计数，最多同时处理 4 个目标。
- 上位机：图像接收、算法切换、参数配置、检测结果与计数显示。
- 人脸和独立 TRACK 模式未启用。

## 使用

1. 硬件工程入口：`td_project/ball_face.al`。
2. 上位机环境：运行 `安装环境.cmd`，完成后运行 `启动上位机.cmd`。
3. 位流：`output/ball_algorithm_gui_managed.bit`；文件信息见 [发布记录](docs/基准位流.json)。
4. 文件检查：`python scripts/verify_package.py`。
5. 源码构建及仿真：[构建说明](docs/构建说明.md)。
