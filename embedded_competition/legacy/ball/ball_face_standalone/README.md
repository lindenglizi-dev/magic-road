安路HX1P35B开发板工程，器件PH1P35MDG324，速度等级-3。开发工具为Tang Dynasty 6.2.168116，顶层模块design_top_wrapper。

## 功能

摄像头输入1280×720、60帧视频，FPGA每拍处理4个像素。开机先进行人脸位置检测，五个256×256区域轮询；同一区域连续三次确认后解锁小球检测。HDMI显示成功提示、目标框、中心坐标及统计数据。

TRACK模式识别红、绿、黄球并跟踪位置；COUNT4模式维护最多四个目标，从左向右跨过计数带时按颜色去重计数。板载数码管轮换显示各色球数量及形状/尺寸拒绝候选次数。显示支持亮度曲线和白纸校准。

## 随包bit

随包bit与整理前已发布的优化版逐字节相同。本次仅清理注释、工程根路径和三个ROM路径，不改变运算、接口、复位、时序约束或硬件功能；未重新布局布线生成随包bit。

该bit已有25项功能检查及安路原生布局布线记录：Setup WNS +0.704ns、Hold WNS +0.020ns，TNS及违例端点均0。资源为Slice17895/21216、LUT6 17266/21216、寄存器17621/42432、ERAM103/108、DSP37/40。上述数据属于随包bit，重新编译后应以新报告为准。

整理后的源码另行完成token、ROM、约束、文件引用与安路原生展开检查，结果见verification。实际摄像头、光照和球速仍需板上验证。
