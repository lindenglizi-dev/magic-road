# 使用说明

## 启动

1. 接好摄像头、HDMI和板卡电源，下载release/ball_face.bit，等待图像稳定。
2. 人脸移入显示的扫描区域，同一区域连续三次确认后出现绿色“识别成功”，小球功能解锁。这里只检测位置，不识别身份。
3. TRACK用于动态追踪；COUNT4用于左至右去重计数。球之间保持可见间隔，避免复杂遮挡和紧贴的同色球。

人脸扫描区域左上角依次为(512,232)、(384,232)、(640,232)、(256,232)、(768,232)，每区256×256；覆盖并集x256～1023、y232～487，不是全画面。解锁后停止人脸检测，离开画面不会自动锁定。

小球ROI为x64～1215、y160～639。计数线x640；目标先在x≤624处被实际观测两次完成准备，再实际越过x≥656时计数一次。预测位置不会单独触发计数。连续失联8个检测帧后释放计数轨迹。

## 按键

按FPGA引脚定义，板卡丝印可能不同。短按功能在松手后生效，部分操作在下一帧边界提交。

| 按键 | FPGA引脚 | 短按 | 长按 |
| --- | --- | --- | --- |
| KEY1 | D5 | TRACK / COUNT4 | 循环曝光档位 |
| KEY2 | A9 | 原图 / 颜色掩膜 | 循环增益档位 |
| KEY3 | B9 | NORMAL / STRICT | 白纸显示校准 |
| KEY4 | C7 | 清空各色球及E计数，保留解锁 | 约1秒后清空并重新锁定人脸 |

相机侧原有N2、J14按键连接保留；曝光、增益以HDMI显示为准。

白纸校准时用白纸覆盖画面中心128×128区域并长按KEY3，等待WBCAL变为WBSET。过暗、过亮或样本不足会显示WBERR并保留已有增益。校准只影响显示，不反馈颜色分割或人脸算法；KEY4操作保留校准，断电后恢复默认。

## 数码管

将SW6拨到数码管侧，手册标注为拨上；拨在LED侧时数码管不亮。相机产生CSI时钟后开始扫描。

每2秒轮换r./G./y./E.四页，首位为类别，后7位为数量。G字形接近数字6。最大显示9999999，达到显示上限时末位小数点亮；内部颜色计数保留32位，HDMI显示完整数值。

E表示形状或尺寸规则拒绝的候选累计次数：同一候选同时违反多条规则只加1，同一物体跨帧被拒绝会继续累计。仅面积不足且没有形状/尺寸拒绝标志的候选、视频故障和正常目标不计入E。E不是实际漏计/误计数量，也不是去重后的错误球数量。

| 信号 | 位序 | 引脚 |
| --- | --- | --- |
| O_seg_segments_n[0..7] | a,b,c,d,e,f,g,dp | C9,C11,B11,E7,E6,B6,B7,E5 |
| O_seg_select_n[0..7] | 左起第1～8位 | G15,G14,A17,A18,B16,A15,B15,A14 |

段选和位选均低有效。切换时先全灭约1us，段码稳定约1us后选通下一位，完整八位刷新率约500Hz。
