# 第三方资源

user_source和td_project/al_ip包含安路及原开发板参考设计的摄像头、ISP、DDR、HDMI和IP文件，保留原厂商版权声明、综合属性及IP描述。

人脸检测采用OpenCV的haarcascade_frontalface_default级联模型，定点参数位于rtl/face_rom/stumps.mem和stages.mem，缩放坐标表为coordinates.mem。共25级、2913个弱分类器。源模型SHA256：0f7d4527844eb514d4a4948e822da90fbb16a34a0bbbbc6adc6498747a5aafb0。许可证见rtl/face_rom/LICENSE_OpenCV.txt。

安路图标用于板卡演示显示。显示字形和图标位图见assets/display_ui，硬件使用的常量位于显示RTL中。
