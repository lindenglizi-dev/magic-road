RoadYOLO G10退化归因与下一步，2026-10-13

结论
本次完成CPU无梯度诊断，没有新训练、没有GPU计算、没有修改数据或原模型。
G10退化不是单一BN问题：BN统计变化明显影响行人；参数更新（含BN的可训练缩放/偏置）也损伤车辆能力。
不采用G10或任何混合模型替换E7，不继续原配方G100，不立即蒸馏。

一、同口径四组对照
固定同一17张开发图、同一标签/ignore/输入处理、同一排序与后处理。
Precision/Recall在置信度0.5、匹配IoU0.5处统计；AP50仍使用原分数下限约0.05。
每类Top128、最多32框、NMS IoU0.5均未改变。

模型                      行人P / R / AP50              车辆P / R / AP50
E7原版                    80.77 / 22.83 / 39.00         78.00 / 44.83 / 49.57
G10原版                   56.00 / 15.22 / 28.04         40.48 / 19.54 / 28.52
G10参数 + E7统计           63.83 / 32.61 / 40.70         46.15 /  6.90 / 33.21
E7参数 + G10统计           50.00 /  6.52 / 10.67         48.18 / 60.92 / 50.58
以上单位均为百分比。

G10参数换回E7统计后：行人AP50高于E7 1.70个百分点，但精确率仍低16.94个百分点；
车辆AP50仍低16.36个百分点，召回率只剩6.90%。所以不能把“换回BN后行人变好”当成两类模型已经修好。
仅将E7统计替换成G10统计，行人AP50由39.00%降至10.67%，证明统计变化对本开发集影响很大。
同一替换却使车辆召回增加、误报从11增至57，进一步说明BN影响不是简单的全局好/坏开关。

二、为什么只有10次更新也有显著影响
模型有61个BN层，momentum=0.03、eps=0.001。
训练22张图按8、8、6分成三个小批；每次前向BN都更新一次，梯度累积并不合并BN统计。
10次参数更新实际对应30次BN更新；各层计数均从153030到153060。
原运行统计的系数为0.97^30=40.10%，最近30个小批的合计系数约59.90%。
这里是指数移动平均的系数，不代表增加了59.90%的独立场景或信息。
数据只有22张且反复呈现，统计分布容易发生较大变化；这不是内存不足或未完成训练的证据。
两个模型全部状态数值有限，G10优化器动量有限；未发现NaN/Inf。
参数与统计存在明显交互，不能把指标下降按百分比拆成“BN占多少责任、权重占多少责任”。

三、低分漏检补充（只分析已经保留下来的预测）
仍使用原分数下限约0.05，只临时查看全部保留框的匹配，不改变模型工作阈值。
                         0.5以上TP / 全部保留框TP / 全部保留框FP
E7行人                   21 / 53 / 149
G10行人                  14 / 54 / 415
E7车辆                   39 / 54 / 184
G10车辆                  17 / 49 / 156
G10行人不是所有候选都消失：低分正确框仍存在，但排序/置信度质量及低分误报显著恶化。
G10车辆既有高分正确框减少，也有全部保留框中的可匹配目标减少。
单纯降低置信度不能解决两类精确率问题；本次没有修改阈值。
这些计数不能证明原始检测头完全没有候选，也不能区分分数下限、框位置、TopK或NMS各自的损失；
没有做逐层或原始检测头干预，不把未知原因写成定论。

四、建议的下一步（本次未启动）
1. 继续保留E7为唯一基线；不从G10或混合状态续训，不再要求本轮新增人工标注。
2. 若启动新的独立保守短实验：从E7重新初始化，固定61层BN运行统计，并冻结BN可训练缩放/偏置；
   学习率由0.001降至0.0001，最多10次参数更新，其余数据、顺序规则、增强和损失保持原配方。
   这是组合式稳定性试验，不宣称能单独证明学习率或冻结BN哪个因素贡献多少。
3. 训练前先做最小验证：进入train、完成验证再返回train、保存恢复后，BN仍冻结；
   优化器中不含BN可训练参数，训练结束BN统计和仿射参数逐项等于E7。冻结策略须写入恢复协议。
   不能只在最开始调用一次BN.eval()，因为训练器后续model.train()会重新开启BN更新。
4. 同样22图、microbatch8/accum8，尾批提交下实际有效batch仍为22，不冒称64；
   10次更新=10遍/220次图像呈现。每次更新保存，沿用温度、时间及磁盘保护，不覆盖旧目录。
5. 评估同一17图，再检查原256图回归。开发门槛仍是行人AP50相对E7至少+1个百分点、
   行人固定阈值召回不下降、车辆AP50下降不超过1个百分点，且分机位及原256回归无明显退化。
   记录两类P/R/AP50/AP50:95与误报，不能只挑行人改善的一项。
6. 达到门槛后再决定继续小预算监督实验；不达标停止，不直接追加G100/蒸馏。
   冻结BN再训练不等同于本次推理时交换BN，不能保证会复制混合模型的指标。
