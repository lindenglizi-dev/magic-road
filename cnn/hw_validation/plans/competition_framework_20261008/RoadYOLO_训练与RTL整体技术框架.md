# RoadYOLO 比赛系统训练与 RTL 整体技术框架

日期：2026 年 10 月 8 日。适用工程：`lab1_sc500_road_vision`，器件 PH1P35MDG324，速度等级 −3，CNN 目标时钟 100 MHz。

## 主要决策

训练主线继续使用我们已有的 **RoadYOLO-S4-512 学生模型和冻结 E7 权重**，不是从零重训，也不改成外部的 YOLOv4、Yolo-FastestV2、FastestDet 或 NanoDet。外部官方 YOLOX-S 继续只作为开发端教师，辅助标注和后续蒸馏；比赛运行不依赖教师、PC、GPU、CPU 或 NPU。

硬件主线保留已经对拍的 **24 MAC、signed33 跨组累加、最近偶数重定标和共享 SiLU**。重点借鉴外部工程的输入复用、输出预留、加载与计算与写回重叠，以及同一个模型包驱动参考与硬件。下一项结构实验选定为 **DW 同通道三相邻空间点打包**，不先造通用加速器，也不先更换网络。

当前网络不是准确率已达标的网络，当前小块也不是整网已达到 5 FPS。未通过的具体问题是：道路完整验证真值尚未发布；部署等价 QAT 尚未完成；最新完整物理候选有 5 个内部 setup 失败端点，最差 −0.943 ns；完整 DDR、67 层及 FPGA 后处理尚未形成运行闭环。接口和严格检查的未闭合项继续独立记录。

本框架确定后续设计方向、借鉴范围和接口，不把规划模块当成已写好的 RTL。本文没有启动训练、改动生产工程、生成位流或操作板卡。训练和 RTL 的最新证据、对话对应关系见 [证据索引与对话进度](证据索引与对话进度.md)。

## 一 为什么不现在更换训练网络

目前缺少的是可靠道路标签、正确训练域、真实量化参数和高效调度，不是一个新的 YOLO 名称。新标签实验已经有 E7 起点、19,049 张训练图、5,151 张原验证图和已通过 CPU 对拍的缓存。直接换网会同时重做初始化、正样本分配、头部解码、量化及 RTL 适配，不能修复漏标和域偏移。

我们的模型已经只有 113,100 个卷积权重。FastestDet 官方软件模型约 0.24M 参数，但其单尺度 stride16、Shuffle、5×5 DW 和不同解码不是当前 S4 小目标网络的低风险替代；作者 CPU 速度不是本板 FPGA 速度。[FastestDet 官方说明](https://github.com/dog-qiuqiu/FastestDet)

具体选择如下：

| 对象 | 后续决定 | 与当前工作的承接 |
|---|---|---|
| 当前 RoadYOLO 学生 | 保留并从 E7 开始审核标签后的短实验 | 模型、缓存、损失、图描述、整数参考和已验证算子继续使用 |
| 当前官方 FP32 YOLOX-S 教师 | 保留；先辅助人工审核，之后有限蒸馏 | 不把教师预测直接变为真值，不把教师权重直接装入不同拓扑的学生 |
| 外部八个项目的完整网络 | 不作为本阶段替换目标 | 避免同时新增 Shuffle、anchor、DFL、softmax、5×5 DW 或新激活 |
| 唯一缩网备选 H24 | 仅在周期证据需要时做一次软件对照 | 只把三尺度解耦头内部 48→24；保留骨干、PAN、S4/S8/S16 和解码 |

“继续当前训练”不等于继续已失败的旧 E7→E12 配方。E12 的完整旧验证集 AP50 比 E7 两类均下降，因此后续使用 **审核标签后的 S 实验**，其轮号从 S1 开始，不能冒充旧实验第 13 轮。

## 二 冻结的网络结构

主网络仍以 [cnn/model.py](../../../model.py)、[cnn/contract.json](../../../contract.json) 和 [冻结图](../../production/graph_artifacts/graph.json) 为结构依据。软件输入用 NCHW，DDR 输入用 NHWC；通过显式布局转换连接，不能混用。

| 阶段 | 固定运算 | 输出 W×H×C |
|---|---|---|
| 输入 | 1280×720 RGB 精确 2/5 面积缩放，卷积入口 pixel−128 | 512×288×3 |
| Stem | 普通 3×3，stride2，3→16 | 256×144×16 |
| P2 | DW3×3/s2→PW16→24；CSPLite 两个半通道残差单元 | 128×72×24 |
| P3 | DW3×3/s2→PW24→48；CSPLite 三个半通道残差单元 | 64×36×48 |
| P4 | DW3×3/s2→PW48→96；CSPLite 三个半通道残差单元 | 32×18×96 |
| SPPF | PW96→24；连续三次 maxpool5×5/s1；四路 concat；PW96→96 | 32×18×96 |
| 自顶向下 | P4 压至48并 nearest×2 融合 P3；再压至24并融合 P2 | 64×36×48、128×72×24 |
| 自底向上 | P2 下采样融合 td3；再下采样融合 P4 | 64×36×48、32×18×96 |
| 三个解耦头 | PW→48；cls 和 reg 各 DW3×3→PW；独立 cls2、reg4+obj1 预测 | 128×72×7、64×36×7、32×18×7 |

CSPLite 保留一半通道旁路，一半执行 DW→PW 残差单元，最后 PW 融合。PAN 的 FusionCSP 先将 2C 压至 C，再在半通道上执行一个残差单元。激活使用 SiLU，训练保留当前 SimOTA 和检测损失，不同时引入 NanoDet 的 DFL/QFL/DSLA。

每个点的输出顺序固定为：

```text
tx, ty, tw, th, objectness, person_logit, vehicle_logit
```

这些七项输出已经存在，不是本次从 FastestDet 新增的结构。YOLOX 框表达仍为 `cx=(tx+grid_x)×stride`、`cy=(ty+grid_y)×stride`、`w=exp(tw)×stride`、`h=exp(th)×stride`。保留三尺度 12,096 个位置，不删 S4 小目标头。

结构数量为 67 个卷积，其中 1 个普通 Stem、23 个 DW3×3、43 个 PW1×1；61 个 SiLU、3 个池化、12 个残差、7 个 split、15 个 concat、2 个 nearest upsample。全帧 214,465,536 MAC，2,501 个折叠偏置。静态图含 106 个节点，不等于存在 106 个专用硬件模块。

类别仍为 person、vehicle。vehicle 合并汽车、公交、货车、自行车、摩托车；骑行者人体与车体分别标注，允许两类框重叠。运动和静止目标都检测。最终原门槛保持两类分别 Precision≥95%、Recall≥85%、IoU≥0.5、有效检测≥5 FPS；展示优先改善 Precision 和 AP50，不通过删除困难目标提高成绩。

## 四 总体系统与官方模板的关系

本系统继续以官方模板一 `lab_ex1_mipi_hdmi_SC500_720P` 为视频底座；独立 [cnn/template/design_top_wrapper.v](../../../template/design_top_wrapper.v) 是视频模板入口。根目录 CURRENT_ARCHITECTURE 描述的 CCL/HOG/SVM 是历史实现，不是本 CNN 目标图。

```text
SC500 → 官方 MIPI/ISP/AWB ─→ 官方视频 DDR 环形区 ─→ HDMI 视频
                         │                              ↑
                         └→ 彩色 2/5 面积缩放            │
                            → 两个独立 DDR 输入槽       │
                            → 固定图执行器              │
                              ├ 24 MAC                  │
                              ├ 动态重定标 + SiLU       │
                              ├ 池化/残差/视图地址      │
                              └ tile 读写               │
                            → INT16 三尺度预测          │
                            → FPGA 解码/Top-K/NMS       │
                            → 完整结果表 CDC → SOF 切表/64框叠加
```

在后续单独 CNN 集成顶层中不实例化背景差分、CCL、灰度 ROI、HOG、SVM、几何分类和旧四目标跟踪事件支链。保留历史源码用于恢复，不把它们同时带入 CNN 资源预算。当前不新增跟踪或越线功能；先完成真正的检测和显示闭环。

官方 PLL、摄像头配置、视频 DDR 环形 bank、HDMI 直播时序不因 CNN 慢而降低帧率。CNN 忙时跳过完整源帧，HDMI 继续直播。

时钟边界沿当前集成契约：摄像头 AWB 域、100 MHz CNN 域、DDR user 域和 HDMI 像素域。具体频率沿原配置；不靠增加频率或时序例外凑 5 FPS。CNN 算术、层控制和后处理放同一个 100 MHz 域，减少内部 CDC。

## 六 接口与数值契约

### 通用传输规则

同域所有可停顿通道只在 `valid && ready` 时消费一次。valid 等待 ready 时 payload 保持；计数不随裸 valid 推进。复位/取消优先于新任务和成功提交。已经接受的 DDR 请求仍需登记、归属并排空，不因 CNN 算术核即时取消就提前释放存储。

顶层保持异步断言、同步释放；沿现有两级释放寄存器，外部复位拉高后的两个有效上升沿完成释放，最早第三个上升沿接受接口传输，不把亚稳态可能增加的等待当作固定零延迟。装表及模型包检查完成前启动许可为 0，计算输入 ready/输出 valid 为 0；装表通道按自身握手开放，不能同时封住装表入口。复位即时取消旧算术事务，释放后必须重新按现有接口装满 1024 项 SiLU 表；不依赖未验证的初始化内容。内部核的复位端口不批量修改。

### 输入像素和输入槽

AWB96 每拍四个 RGB888 像素，按 `[95:72]、[71:48]、[47:24]、[23:0]` 序列化，每像素 R[23:16]、G[15:8]、B[7:0]，沿当前 [集成契约](../../../spec/integration_contract.md)。彩条和编号图确认实际方向后才接摄像头；不能继承旧灰度模块的低 lane 优先假设。

缩放横向五样本产生两点，权重分别 `(2,2,1,0,0)` 和 `(0,0,1,2,2)`；纵向同样加权，总和除25只做一次 RNE。横向中间至少11位，二维和至少13位。四输入像素一拍可能产生两个横向输出；适配器至少支持两 lane 或等价有界缓冲，不能假设单像素每拍足够。

缩放逻辑接口采用 `valid, sof, eol, eof, x[8:0], y[8:0], lane_mask[1:0], rgb[47:0]`。x/y 指第一有效输出点坐标，双 lane 在同一行相邻；行尾不跨行拼接。输出进入 capture 缓冲，摄像头不可被 CNN ready 反压；溢出取消整帧，不发布半帧。

每帧 payload 必须恰为 442,368 字节，DDR 输入保留 UINT8 RGB，不提前转 signed。pixel−128 在 Stem 读入时做一次。

任务描述符沿既有契约，增加共享时基时间戳字段：

| 字段 | 位宽或固定值 | 含义 |
|---|---|---|
| epoch、task_id、source_frame_id | 各32 | 源物理 SOF 帧号包含跳过帧；协调重启切换 epoch |
| model_id、resize_id | 各32 | 模型包和预处理版本，不用文件名代替 |
| tensor_slot | 1 | 两个输入槽之一 |
| tensor_base、payload_bytes | 各32 | 逻辑字节地址；payload固定442368 |
| capture_timestamp | 64 | 共享100MHz时基；不是各域自行数帧换算 |
| width、height、format | 512、288、RGB888/NHWC | 固定输入，不新增多分辨率配置 |

槽状态仍为 `FREE→CAPTURING→READY→READING→FREE`。SOF 无 FREE 则整帧跳过。READY 必须有可靠写完成/读可见性证据；最后一个输入读响应消费且无在途请求才释放，不等整网 done，也不只看 DMA 请求发完。

### 层描述符与张量布局

节点 ID 用7位容纳106节点；卷积层号也用7位。固定图描述符至少包含：op、src/dst tensor或视图 ID、H/W各10位、Cin8位、Cout7位、kernel/stride/pad、权重及量化字节偏移32位、输出类型、SiLU/residual标志、tile坐标及终止条件。H/W用10位，避免9位无法表示宽度512。仅支持当前算子白名单，不预留 arbitrary kernel、dynamic shape 或新的网络解析器。

DDR 输入是普通 NHWC；特征图采用现有 `tile4x4_hwc`，真实通道不补齐到8，INT16小端。元素地址为：

```text
tile = (y//4)*ceil(W/4) + x//4
local_pixel = (y%4)*4 + x%4
addr = base + (tile*16*C + local_pixel*C + c)*bytes_per_element
```

split/concat/nearest 通过现有 graph 的视图映射解析，不写完整拼接/上采样张量。残差视图不等于免费加法：branch 写回时读 bypass，完成尺度一致的 signed9 加法并 sat8。卷积逻辑越界取0；池化逻辑越界取−128；物理 tile 空槽填0，这三种情况不能混为一谈。

初版保留现有70个独占分配，合计7,204,864字节；不先做全网存储复用优化。SPPF池化分别写DDR。描述符是固定控制ROM/表，不占用一份完整特征缓存；具体RAM/LUT映射由新实际顶层报告确定。

### 保留的 MAC 算术接口

| 信号 | 位宽 | 固定语义 |
|---|---:|---|
| activation_data | 64 | 8个signed INT8，低字节为lane0 |
| weight_data | 192 | 三路各8个signed INT8，输出路优先再输入lane |
| bias_data | 96 | 三个signed INT32；只在first加入 |
| lane_mask | 8 | 公共输入槽有效掩码，不是三路输出写掩码 |
| first、last、input_valid/ready | 各1 | 组归约边界和现有握手 |
| result_data | 96 | 三个最终signed INT32 |
| result_valid/ready、fault | 各1 | 结果保持；任一路末组故障按原三路原子规则处理 |

内部33位、结果32位不变。每路最多192个有效乘积、最多24组，不推广到无限累加。包括INT32偏置时，保守绝对值上界 `2^31 + 192×16384 = 2,150,629,376` 小于signed33可表达上界；末组仍单独检查INT32。预测2/5通道、Stem3、半支路12和末块均显式置零输入尾lane并禁止无效输出写回。

同一归约内当前 II=1，但末组后仍有任务关闭、结果确认和下一首组等待。II=1不是每个空间点一拍，也不是不同任务已重叠。

### 动态量化与元数据

权重INT8按输出通道量化；激活INT8按张量、zero-point0；偏置INT32，BN离线折叠。部署以 [deployment_contract schema2](../../production/deployment_contract.json) 为准，不能使用现探针固定1/3/5系数代表真实模型。

活动参数记录如下，数值包仍按原uint8 shift保存，读取时验证0…62后送6位端口：

| 参数 | 位宽与范围 | 使用位置 |
|---|---|---|
| bias | signed32 | 当前输出通道，MAC first一次 |
| pre_multiplier、pre_shift | 非负signed32、6位0…62 | INT32→INT64 exact product→RNE/sat INT16 Q7.8 |
| post_multiplier、post_shift | 非负signed32、6位0…62 | SiLU INT16→INT64 exact product→RNE→sat INT8 |
| mode | 1位 | SiLU激活层，或INT16原始预测旁路 |
| parameter_version | model_id关联 | 一个帧任务内不可切换模型/参数 |

只预取当前输出组三路参数及当前层post参数，直接使用同一160-bit物理ROM里的量化字段。不为2,501个通道再增加全量参数ERAM。PW三路参数按三个输出通道选择；DW空间三点的三路参数必须复制同一个通道，不能按物理lane选择不同系数。

动态前重定标和后重定标各一条II=1乘积流，采用现有精确INT32×UINT31拆分参考，保留足够64位宽；预留最多各3个DSP的设计空间，实际成本必须综合。两个乘积级可与round、SiLU及写回重叠，不能用固定系数26DSP报告代表动态版本。

`road_round_shift` 接口继续是product64、shift6、tag16、ready/valid，输出INT16。`silu_shared_unit` 表接口继续addr10/data16和计算INT16。tag16作为有界在途记录索引，不再硬编码成`{layer1,position4,channel5,...}`。

外部元数据记录保存node、frame/task、输出位置与通道、三个写地址、有效输出mask、参数版本和输出类型。预重定标、SiLU、后重定标、写回各级接受数据时必须同步接受tag；背压保持不动。记录在最后一个有效写回被存储端接收后释放；层可见性另由DDR完成屏障决定。复位取消旧记录，禁止旧tag命中新任务。

61个激活层走pre→SiLU→post→INT8。六个cls_out/reg_out预测层走pre→INT16 Q7.8，绕过SiLU和INT8 post；不得先截成INT8再声称原始头逐项一致。

### DDR 与 ROM

暂定输入槽字节基址54,525,952和55,050,240，每槽512KiB。feature开始55,574,528，现图分配结束62,779,392，arena结束67,108,864。即52–64MiB独立区域；未证明实际容量、地址单位和视频不重叠前，不使能真实DMA。

DDR内部请求为 `req_valid/ready + {client_id,epoch,task_id,op,byte_addr[31:0],beat_count,return_owner}`，写数据为128位和16位byte mask。单次CNN连续授予最多16个传输单元，然后重新仲裁；视频读写优先。实际吞吐必须包含由此造成的等待。

控制器端AR、AW、W分别按自身ready接受；按厂商PAXI允许的顺序组织AW/W，不照搬其他仓库AXI master。每个读请求先预留完整返回容量并记录owner；没有RREADY的返回也必须能被接纳或按已取消owner丢弃。写接受不等于写可见，不能虚构不存在的B响应，也不能固定等N拍代替完成。

数值包沿原小端顺序，payload140,522字节，物理填充至143,360字节，160-bit一词20字节、14组×512词×4个40-bit lane。56 ERAM只是布局目标，必须确认真实映射。权重以现包的OIHW保存；活动tile参数/权重预取做lane重排，不改变包的数值含义。读取完整20-byte词时处理层尾、未对齐偏移和组交界。

reset后自动由片上ROM装载活动SiLU表，结束前禁止计算。原型还须保留窄口装表回归入口；最终ROM初始化与Flash自主启动作为单独集成任务，不在本框架阶段宣称通过。

### 框解码与显示

原始三尺度头为INT16 Q7.8，共169,344字节。解码先将tw/th裁到Q8的−1024…896，使用共享exp表；objectness与两类logit分别使用sigmoid表。vehicle已经是网络中的一个合并类，不再在硬件增加五种车辆分类头。

分数固定 `RNE(obj_uint16×cls_uint16/65536)`。两类各独立Top128，按score降序、cell ID升序；cell ID依次stride4/8/16，再行优先。每类最多32个框，总64。NMS只在同类别内比较，IoU严格大于0.5时抑制，即 `3×intersection > area_a+area_b`；等于0.5不抑制。计算面积与3倍比较前显式扩展位宽；网络已裁边Q8框可用40位面积、42位比较，不允许中间回绕。

框采用连续半开xyxy。先在网络Q8坐标裁边，再一次RNE换回源图：`source_pixel=RNE(network_q8×5/512)`，裁到1280×720；源结果接口以无符号Q12.8的20位坐标保存，即整数源像素左移8位。阈值按验证集冻结；不在RTL写默认0.5冒充最终最佳阈值。

结果元数据沿既有接口：epoch/task/source_frame/model各32位、box_count7位、result_status2位、capture和completion时间各64位。0为完整有效结果含空表，1取消，2输入/计算/存储故障，3保留。每框class1位、score16位、xyxy各20位。payload冻结至目标复制确认；确认复制不是HDMI立即画框。

跨域先收完整pending表，仅HDMI SOF切active，整帧稳定。共享100MHz时基由明确的帧事件/时间快照协议提供，不能直接异步采64位计数器，也不能拿两个独立帧计数相减解释毫秒。先在100MHz域接收源SOF事件登记时间，所有结果沿这一时基；该登记时间晚于实际源SOF，不能直接称为精确拍摄时间。向HDMI传递同源时间快照，分别界定源SOF事件传递、时间快照老化和HDMI采样的最大误差，年龄比较把这些误差上界加回，避免因CDC延迟低估年龄。具体实现承接现有快照机制，不私自新增异步FIFO或外设协议；无法给出有限误差上界时，500ms项目仍记未通过。

在SOF判断结果年龄超过50,000,000 tick即500ms，则整帧不画该表，显示年龄/超时状态。旧结果过期时必须撤框，不能一直保留最后一次框冒充连续检测。

## 七 选定的 DW 和 PW 调度

### DW 同通道三空间点

当前DW探针每个任务只提交一个标量，只有一条输出路有真实权重；9个有效乘积占两组共48个物理乘法槽，利用率18.75%。因此不先增加更多DSP，而是把同一通道、同一输出行的三个相邻输出位置放入三条输出路。

| DW3×3场景 | 三窗输入并集 | 分8输入组 | 有效乘法槽占比 |
|---|---:|---:|---:|
| stride1 | 3×5=15点 | 2组 | 27/48=56.25% |
| stride2 | 3×7=21点 | 3组 | 27/72=37.5% |

并集按行优先固定排列。每个A广播给三路，属于该输出窗的位置使用相应核权重，其余权重为0；三路各自仍完成原9项DW卷积。尾组input mask对s1为7个有效槽、s2为5个；这是并集槽数，不是各路真实9项乘积掩码。

不跨输出行打包，不扩展到5×5或任意卷积。行尾只有1/2点时禁写缺失路，缺失路权重与bias清零。图像padding输入为0，不能写入下一行。每路bias在first加入一次，三路采用相同通道的量化参数。输出mask与三路写地址同步锁定。

打包改变了部分和的排列，但无中途舍入；应对拍各路最终acc、pre、SiLU、post与实际写地址，不要求与旧逐组轨迹逐拍相等。signed33和末组INT32故障规则保持，一条有效路故障仍按原三路原子规则失败。

第一候选仅用一个最多21字节的并集缓存和三路稀疏权重组，不先增加多累加context。4×4/s2的原9×9 halo可以支持该实验。先测G=3、内部点、四边padding、行尾1/2点、背压、复位和无重复写。固定诊断系数必须按逻辑通道复制，不能把现固定stream的物理lane系数直接沿用。

该结构减少DW任务和无效乘法，但地址生成、参数选取及写回会有成本；上述占比是数学槽利用率，不是实测FPS。新的调度与存储实际顶层必须重新计周期和实现。

### PW 4×4 输入及权重驻留

PW缓存当前tile全部16×Cin激活；一次取8个输入通道，三组权重计算三个输出通道。输入块和三通道权重块装好后，依次处理本tile的16个位置；权重不为每个像素重新从ROM读取。

每路归约组数 `ceil(Cin/8)`，最大Cin192、24组。Cout尾路只屏蔽写回，Cin尾lane必须置0并mask。先保留单归约context及现有两组结果reservation；只有前一任务的原协议已允许重新接受时才发下一first。下一任务首组预取只是减少存储等待，不改变MAC结果确认规则。

不用外部512路阵列，不新增跨任务MAC重叠作为本阶段默认。DW空间打包实测后再看剩余PW周转；只有周转仍占主要预算，才提出一个明确的核级连续任务候选，不能每解决一项就追加另一套通用context设计。

## 八 训练接续计划

### 已有训练资产如何使用

S实验从冻结 `epoch_0006.pt` 加载权重；这个零起始文件名表示已完成7轮，即E7。它的SHA256与架构见证据索引。E12只作失败对照，不作为下一起点。CPU缓存24,200条已逐项等价通过，不再为同一未变像素重复制作约10GiB副本。

当前训练19,049图中127帧更新为人工审核标签，1帧排除，剩余18,922帧未经本轮人工复核；训练域仍主要是VisDrone航拍。128图审核不能被解释为全部数据已经标全。

道路Ground48用于短实验的可信开发比较，不进入训练。当前磁盘未发布完整人工真值；教师橙框支持人工多选/全选后取消、采用和编辑，但采用只是草稿，不能自动签署complete。来源绿框少的部分停车场帧必须补全，不能把未标车辆当背景。优先利用教师预画降低手工工作量，不要求重画正确绿框或重复审核已完成128图。

### 有限的 S 实验

1. 完成Ground48全帧人工修订并导出正式patch，发布新开发真值。用已经完成的缓存收据和真实index SHA执行一次完整validate-only，不再重复同内容全缓存对拍。
2. 同一Ground48、同一部署后处理先测E7道路基线。原5,151图和旧256图各保持自己的名称与旧标签口径。
3. S1/S2只加载E7权重、新优化器；SGD，恒定LR0.001，microbatch8、累积8、有效batch64，AMP，Mosaic关闭，seed42。每轮298次更新，S2累计596次。每个完整更新/轮边界可保存暂停；保护参数沿当前已批准启动器，不增加空闲内存硬门槛。
4. S2分别评Ground48、完整5,151和旧256。Ground48 person AP50较E7至少+1个百分点且R@0.5不下降，vehicle AP50下降不超过1个百分点；5,151图两类AP50下降均不超过1个百分点，才同一实验续到S5。机位趋势冲突或样本不足记inconclusive，不强行续轮。
5. S5选权重仍按Ground开发证据和原回归约束；不自动续到20或300轮。48图只能判断是否值得继续，正式P95/R85仍需更大、完整、机位隔离的数据。

S实验优先定位数据修正是否产生真实收益。如果S2失败，先用已经有的漏检归因图区分缺候选、低分和定位错误；不能把缩头当作修复标签的方法，也不同时扫描八个网络。

### 道路适配 蒸馏和 QAT

S阶段有正收益后，下一批数据优先补**真实地面固定机位、完整人车框、静止车辆和骑行者**，不是继续扩大航拍邻帧。用户现场视频保留原片、机位和拍摄条件；开发视频可以参与训练，但与最终独立测试机位/原片隔离。没有现场视频时先用标注覆盖更完整的公开固定机位数据。

训练结构不变时，下一段道路微调以短2轮比较、最多5轮为基本单位，不预先承诺“训练满300轮才能完成”。两类失衡或两轮车不足时只调整数据采样/补标，单变量对照，不同时换loss和head。

蒸馏沿现有官方FP32 YOLOX-S教师与缓存，只加入训练端objectness、class、box监督；保留人工GT和SimOTA。先一段短对照，教师错误不写入GT。现有教师适配逻辑已将五种车辆映为一类，不另造教师体系。具体蒸馏权重与轮数在S结果后按现有配置冻结，不本轮凭空指定多个loss试验。

QAT必须补齐当前缺项后才启动：BN折叠、逐输出通道权重scale、INT32 bias、acc→Q7.8重定标、精确SiLU表、SiLU→INT8重定标、concat/residual尺度对齐、INT16预测、tw/th裁剪及全部饱和。当前`prepare_experimental_qat`只是部分实验钩子，不能用通用fake quant冒充部署等价。

QAT从通过开发比较的FP32权重开始，以5轮短段评估，只有量化损失和任务指标有恢复才再续；30轮是原计划上限方向，不是必须一次跑满。最终量化mAP50相对同拓扑FP32下降不超过1个百分点，阈值仍在验证集选择并冻结。

### 唯一缩网备选

若DW空间打包和PW预取后，含DDR/后处理的逐层预算仍无望接近20M周期，唯一软件备选定为 **RoadYOLO-S4-512-H24**：三head的stem、cls_dw、cls_pw、reg_dw、reg_pw内部48→24，cls_out2/reg_out5不变，骨干/PAN/SPPF/S4/8/16/SiLU/七项框表达全部不变。

按当前冻结图算术统计，H24为156,114,432 MAC、96,900卷积权重、2,141折叠偏置，仍67卷积/61SiLU。比原网少58,351,104 MAC，即27.2%；这些是结构计算，不是训练结果、实际周期或资源报告。H24仍不能保证5FPS，DW空槽、DDR和控制成本必须实测。

仅做一个H24候选，与同数据、相同训练预算的H48对照；未改形状的骨干/neck可加载当前权重，头部形状改变的层明确重新初始化或按已验证规则移植，不强行strict=False掩盖遗漏。H24冻结新architecture/model_id、导出包和预算，不覆盖原H48。只有精度及周期同时更有利才切换；不因为S2标签实验失败就自动缩网。

## 九 执行顺序和完成条件

训练和硬件可并行推进，但真实量化包冻结后才合流。每段的目标是产出能影响下段决定的证据，不额外扩展安全审计或重复扫描整个历史目录。

| 阶段 | 具体执行 | 最小交付与决定 |
|---|---|---|
| A 当前时序收口 | 继续已有ack-local独立候选，修5条控制路径；原向量回归和实际顶层TD | 全量内部setup/hold及适用复位检查；外部I/O仍单列，不用改约束变绿 |
| B DW空间三点与PW预取 | 先Python排布参考，再现有核适配；s1/s2三点、G3、尾路、原子故障及复位背压 | 完整DW/PW同向量端点周期、DDR/RAM读量、参数/写地址对拍；新实际顶层资源及时序 |
| C 最小动态参数链 | 从同一包读活动参数；动态pre/post乘积；INT8与INT16预测分型 | 一层真实或明确测试参数逐级bit-exact；动态乘法真实DSP成本；不沿用固定26DSP |
| D 固定图执行与DDR | 当前图专用sequencer、tile I/O、pool/residual、PAXI归属和写可见性 | 67卷积及必要非卷积完整张量对拍、每层互斥周期原因、持续视频优先等待 |
| E 精度分支 | Ground48→E7基线→S2→有证据才S5；之后道路适配/有限蒸馏/完整QAT | 分开发集报告P/R/AP50、原回归和漏检分类；选唯一模型包 |
| F 吞吐结构决定 | B/C实测更新预算；若仍明显超20M只比较一个H24，不无期限拖延 | 决定保留H48、切H24，或提出具体核级周转请求；不隐瞒差距 |
| G 整机闭环 | 真模型包、FPGA decode/TopK/NMS、完整表CDC与64框HDMI；官方模板集成 | 整机布局布线、真实全帧周期，之后独立精度/板测/自主启动 |

阶段A、B、C可在当前独立验证目录推进；阶段G涉及正式集成、位流和板卡的操作仍在对应授权与设备具备后执行。本文不把规划自动变成训练或生产修改命令。

当前5,433周期只测down2的一个4×4 DW→PW小块。最新条件帧预算63,662,586周期尚未含完整DDR、pool/residual和解码/NMS；100MHz的5FPS上限为20,000,000周期。即使旧预算中未实施的两项理论周转收益都拿到，仍约50,837,370周期，因此本框架不再只围绕SiLU细修，而直接进行DW空间复用和必要结构比较。

完整周期报告按端点总周期和互斥主停顿原因统计：有效MAC发射、输入/ROM等待、任务关闭等待、结果容量等待、存储写回等待、流水排空。pre/SiLU/post忙周期另列活动率，它们可能重叠，不能简单相加。分别报告预装载、核心运行、导出；故障提前退出不能算加速。

总体资源门槛仍DSP≤40、ERAM≤108、Slice≤21,216。schema2的DSP38/ERAM107只是当前规划目标；更早106 ERAM估算是历史口径。小块含壳8,733 Slice/26DSP/1ERAM不能与模板简单相加宣布整机装得下，也不能代表动态参数、完整ROM、DDR和NMS成本。

## 十 必要验证和不做的扩展

必要验证仅保留与本次变化直接相关的四组：

1. **数值**：新调度同向量的acc、重定标、SiLU、最终数据和实际地址；完整QAT与整数模型逐层一致。
2. **传输**：连续输入、随机气泡、长反压、队列满、末组故障、复位取消，以及DDR归属/可见性、整表SOF提交。
3. **实现**：包含新适配/缓冲的真实顶层资源及时序，内部与外部契约分别报告；不新增false path或编造板级延迟。
4. **识别与整机**：同一可信道路GT的P/R/AP50，正式独立测试，以及连续30分钟视频、有效检测FPS、输入跳帧与500ms年龄。

不开展新的通用编译器、UART/AXI控制外设、任意层形状、无限归约、多网络自动搜索或无关格式重写。原严格诊断不删除、不降低要求；以后每个改动只跑相关源闭包，新增模块按readable-verilog-generator完成规定的八项门禁与接口周期图，格式/注释项和真实功能/工具失败分列。诊断通过不等于生产交付通过。

训练侧不重复制作相同缓存、不重复审核正确标签、不自动跑300轮；硬件侧不重复开发已有MAC/RNE/SiLU和图映射。真正需要额外决定的只有：核端口/II/故障语义改变、部署数值改变、真实外设协议、时序例外或正式生产/板卡操作。当前DW空间调度和H24设计均不授权这些隐含变更。

## 简要总结

保留当前RoadYOLO训练资产和官方模板，先把审核标签S实验做出有效比较；硬件保留已验证算术，借外部窗口复用和信用调度，优先验证DW三相邻空间点，补活动量化参数和INT16头，再形成固定图纯FPGA闭环。缩网只留H24一个备选，不删除S4，不照搬CPU后处理，也不把固定系数小块成绩当成模型部署成绩。
