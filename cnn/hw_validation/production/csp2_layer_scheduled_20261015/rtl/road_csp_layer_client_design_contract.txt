road_csp_layer_client 设计契约
日期：2026-10-15
状态：全幅逐层调度RTL候选；不是部署、TD、板测或整网证据。

一、固定接口与启动语义

模块名 road_csp_layer_client，无参数、无MAC实例、无tile输入端口。
i_start仅在o_start_ready为1时接受一次完整72x128 CSP2任务。o_start_ready要求空闲、共同复位已释放、i_table_loaded有效且无故障。
诊断端口o_layer[2:0]、o_tile_y[6:0]、o_tile_x[7:0]只报告当前阶段和4x4块起点，不参与控制。
原248bit参数请求/响应接口和原算术核请求/返回接口的名称、方向、位宽及数学语义保持road_csp_complete_client一致。
内存读接口改为一个未完成的16B逻辑行：o_read_address[31:0]低4位恒0；响应地址必须完全匹配；i_read_response_data[byte*8 +: 8]对应地址偏移byte。
写接口仍为逻辑字节地址和INT8数据，o_write_sum保留精确signed9残差诊断。核输出与外部写只在同一接受沿退休。

二、固定图、顺序与地址

每阶段均遍历18x32共576个4x4块，tile_y为0,4,...,68，tile_x为0,4,...,124，x为内层循环。
阶段严格为DW0、PW0+residual0、DW1、PW1+residual1、fusePW。完整阶段最后一个任务退休后才请求一次屏障；匹配i_barrier_layer且i_barrier_ready后下一阶段才可读取。没有逐tile阶段流水。
五个输出基址依次为0x035ea000、0x03605000、0x03620000、0x0363b000、0x03656000。
DW0读取0x035b4000的通道12..23；PW0旁路读取同一区域通道12..23。DW1及PW1旁路读取0x03605000。fuse通道0..11读取0x035b4000通道0..11，通道12..23读取0x0363b000通道0..11。
所有地址使用tile4x4_hwc：base + ((((y/4)*32 + x/4)*16 + (y%4)*4 + x%4)*C + c)。只有DW的全幅边界halo补零。

三、本地容量与复用

最大块缓存为432字节：DW使用6x6x12；两个残差PW使用16x12输入加16x12旁路共384字节；fuse使用16x24共384字节。
块缓存没有数组复位，任务前覆盖当前阶段要求的全部384或432字节。缓存数组在互斥状态中每拍只进行一次字节写或一次字节读；核64bit输入由同一读口串行拼装。
另有一个128bit行寄存器和32bit完整地址标签。未命中时只发一个16B对齐请求，响应注册后再按目标字节偏移每拍填一个标量字节。
参数驻留为4x192bit权重和一份248bit量化字段。PW当前三输出通道组的2或3个归约分片各取一次，在16个像素间复用。DW每通道分别驻留window5的2组和window3的2组，在4行共8个空间任务间复用；两种窗口权重不混用。
明确的数据容量合计为575字节：块缓存432字节、权重驻留96字节、量化字段31字节、行寄存器16字节；地址标签、控制寄存器、64bit组装输入、24bit旁路及任务元数据不含在575字节内。

四、任务和输出唯一性

每个DW块每通道按每行“三空间点+尾一空间点”执行，共96任务、192输入组、192唯一输出；每个DW阶段共55296任务、110592组、110592输出。
每个残差PW块每三输出通道组遍历16像素，共64任务、128输入组、192唯一输出；每个残差PW阶段共36864任务、73728组、110592输出。
每个fuse块每三输出通道组遍历16像素，共128任务、384输入组、384唯一输出；fuse阶段共73728任务、221184组、221184输出。
DW正常任务输入计数为8+7，尾任务为8+1；12输入PW为8+4；24输入fuse为8+8+8。未用lane由input_mask禁止，不消耗额外缓存读拍。

五、零等待控制账与8M边界

下表假设请求ready立即有效、响应进入等待状态后的第一拍有效、核每拍接受，并进一步假设进入ST_WRITE_WAIT首拍已经有首个核结果、后续核结果连续且写ready有效、屏障第一拍确认。该“零核等待”假设不符合现冻结多级算术闭包，只用于隔离FSM、缓存和端点管理下界；它不是当前RTL实际吞吐上界，也不是DDR、ROM、算术核或板级测量。

六、活性、复位和故障

正常活性链为：启动接受 -> 每块完整预取 -> 当前输出组参数驻留 -> 串行缓存读 -> 核组接受 -> 所有合法写接受 -> 注册flag_task_done -> 推进 -> 整层屏障 -> 下一层或done。
state_current为5bit，ST_IDLE至ST_FAULT编号0..16。flag_task_done在当前任务最后合法写接受后一拍为1，ST_RETIRE只凭该注册事件推进。
参数响应核对layer/channel/group/window/error，后续参数分片还核对248bit量化字段不漂移。读响应核对错误、完整对齐地址。写回核对状态、tag范围、输出mask、未重复和完整地址。屏障核对阶段身份。
共同低有效异步复位清除控制、行缓存有效、驻留参数和故障；不批量复位块缓存。i_cancel、i_core_fault或任一协议错误阻止新提交并进入粘滞ST_FAULT，busy保持，直到所有参与者共同复位；本模块不声称独立取消排空或存储释放。

七、证据边界与剩余风险

本文件不修改旧road_csp_complete_client、冻结算术核、共享owner、DDR/ROM reader、训练、生产顶层、时序约束或位流。
组合地址除法/取模是常量布局表达，资源和时序必须由选定联合顶层的真实综合确认。大字节数组按单互斥读写口编写，但具体ERAM推断及读延迟仍须由目标PDS工具报告确认。
严格门、外部编译、数值仿真、真实DDR等待和全联合TD由总任务统一执行；本契约不把未运行检查写成通过。
