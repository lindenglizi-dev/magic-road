# down2动态小块测试规格

无外部端口测试台，10ns时钟、低有效异步复位。使用安装的PH1P与TD common真实模型。复用四套冻结黄金向量，各10个完整小块；逐项比较MAC、pre、SiLU、post、提交地址与导出。随机反压相位相对核心启动，种子固定；覆盖PW首组/末组/结果/满队列复位、256拍提交反压、末通道INT32原子故障及重新装表。

原始严格门和规范规格入口的无端口拒绝均保留。这份是人工伴随规格，不是规范入口已通过记录，不添加伪端口。

周期图：[PW首组预取](../rtl/waveforms/down2_dynamic_tile_runner_pw-next-first.svg)。首次装表与参数完成前禁止启动；每个合法完整小块640次逐级值检查、384次导出；故障提前退出不计为加速。
