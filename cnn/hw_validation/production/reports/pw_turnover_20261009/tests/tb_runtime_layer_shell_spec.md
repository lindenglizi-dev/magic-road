# 窄口装载与导出测试规格

复用冻结窄口TB，只把独立候选的精确核心周期期望3331改为3204，不修改黄金值。16位RX/TX按ready与valid握手，检查停顿期间输出保持、参数不完整不能启动及1024项表重装。固定与动态压力配置各三个tile，每tile逐个比较384个索引与数值。

这份是无端口测试台的人工伴随规格，不代表规范非空端口入口通过。算术和壳接口未变化。RTL与综合网表共用该TB，网表不加载SDF，不代替时序验收。
