用户已要求先完成整体功能文件，之后再集中优化时序和资源。本阶段不继续纯周转微调、不增加通用架构，不训练、不生成位流、不上板、不写 Flash。必要的数值、握手、复位取消验证保留。严格门禁仍保留，失败候选不能作为正式交付或已验证生产依赖。

“完成”以实际接口能连接、能运行且能对拍为准，不以文件数量或空壳占位为准。

## 本批实际新增

- `road_dynamic_requant.v`：运行时 INT32×非负 INT32 完整乘积，复用冻结 `road_round_shift`，输出最近偶数舍入并饱和的 INT16。系数、shift 和 tag 每次输入握手原子捕获；输出反压冻结整个流水；复位即时取消在途令牌。
- `reference.py`：Python 数值参考、2396 组确定性向量、v19 五个 RTL 文件哈希冻结与核验、接口契约生成。
- `tb_road_dynamic_requant.v`：连续输入、随机气泡、200 周期输出阻塞、在途复位取消、结果顺序与输出保持检查。
- `spec/dynamic_requant/road_dynamic_requant_spec.md`：接口规格及 WaveDrom 周期图已由技能工具实际生成。
- `dependencies/road_round_shift.v`：冻结核的字节副本；原核未修改。

这是一个完整的标量重定标功能候选，不是完整三通道后处理、67 层 CNN 或部署模型。

## 已定位失败及保留记录

1. 沙箱内编译返回 `0xC0000005`，包括 null target；相同源码在批准的本地非沙箱执行下退出 0。记录保留，不把初次编译异常解释为 RTL 数值失败，也不删除失败证据。
2. 初次随机回归失败：测试驱动在下降沿改变 ready 后，用新 ready 判断上一上升沿是否消费，导致未接受的输入被错误替换。修正为保存上一上升沿的实际 `valid && ready`，最终三轮通过。RTL 算术未因此修改。初始日志见 `simulation_initial.log`。
3. 初次周期图生成因沙箱路径解析 WinError5 失败；批准范围内重跑后规格与 SVG 已存在。初始记录见 `spec.log`。
4. 严格闭包门禁仍未通过：161 errors、1 strict warning。`compile/profile` passed；`ast/readability/comment/naming` failed；静态 `testbench/toolchain` not_requested。实际 Icarus 证据独立记录，不改写静态门禁状态。包含格式/注释，以及 VG146 组合来源、VG153 未确认驱动等语义记录，不能笼统说全部只是格式。见 `gate_closure.json`、`gate_closure.md`。这些记录未关闭前不宣称模块正式可交付。
