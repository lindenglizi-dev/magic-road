# DW 与 PW 冻结小块周期测量说明

无端口仿真顶层，DUT 为 inputs/rtl 内八份冻结源码。新增监视只记录事件，
不驱动内部信号、不改变原激励或数值断言；所有源码与原向量纳入冻结校验。

四套测试参数分别含原始和极值固定参数、原始和极值动态参数，每套完成十个完整场景。
每场景逐项比较 MAC、预重定标、SiLU、后重定标和提交各640个值，导出384个字节。
沿用原基础、三空间位置、随机反压、256拍反压、队列满、复位取消和原子故障检查。

## 计时与握手

所有新监视在原有 posedge 监视器中、DUT NBA 更新前采样。start_accept 当拍不计入
运行窗，下一拍 busy 起计，包含 ST_DONE 当拍。DW 到 PW 转换拍仍属 DW，PW 从
ST_STORAGE 起计。四套汇总 CSV 必须与原 candidate_attempt4 逐字段完全相同。

每个核心拍记录状态、MAC/后处理/提交握手、credit与队列占用、三流水活动。
分析器按状态再分局部调度类别，各层互斥桶之和等于实际 endpoint；这些桶不是全部
停顿的根因分类，外部提交反压另计（可与状态驻留重叠）。活动掩码单列，
不把重叠忙周期相加。last 到 result_pop 按 MAC 任务 FIFO 配对；batch 到最终提交
按真实 layer/position/channel 标签配对，并要求无重复、无残留。

每次复位清空测量计数。装表和 preload 计数使用实际 ready/valid 接受事件；span
为首个接受边沿到最后接受边沿含首尾，包含期间测试探针造成的空拍，不等于系统级
启动时延。export_span 为实际 ST_EXPORT 状态拍数，与 DUT 计数交叉核验。

有效载荷未知数一律失败；仅 valid=0 的 commit_tag 或 pp_position/pp_channel
可以保留 None。原始 trace 保留 X，不用零值掩盖。
