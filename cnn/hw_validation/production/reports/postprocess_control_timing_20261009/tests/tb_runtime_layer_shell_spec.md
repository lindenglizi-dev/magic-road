# 窄口顶层功能回归规格

对象为本目录实际八份 RTL 的38位顶层及其安路实现网表。所有计算操作数、偏置、测试量化参数与1024项 SiLU 表由16位窄口装入，不使用编译常量替代。

依次测试边缘、内部、右下角三个4×4 tile，分别逐字节导出384个结果；检查装载不完整不能启动、反压下输出稳定、每个导出序号及数值、完成标志。每套参数导出1152字节，两套合计2304字节。

`+CORE_CYCLES` 必须来自同版本 runner 的无停顿实测端点，禁止省略；本版期望1687。此参数只是比较，不改变被测 RTL。窄口传输周期不代表核心周期。

实现网表仿真不标注 SDF，证明映射后的功能，不替代静态时序检查。全部物理时序报告独立保留；5个权重 RAM 写使能 setup 失败仍是失败。

无顶层端口的 testbench 不满足规范工具的生产模块规格输入；手工伴随规格不豁免严格门禁。
