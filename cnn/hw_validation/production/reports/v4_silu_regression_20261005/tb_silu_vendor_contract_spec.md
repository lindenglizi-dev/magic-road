# tb_silu_vendor_contract 官方 SiLU 关联检查规格

本模块是无顶层端口的仿真测试台，非可综合设计，不伪造端口。DUT 接口、复位、五拍延迟及有效推进 II=1 沿用冻结 `silu_shared_unit` 规格。测试台的容量从 32 扩为 2048 个事务，仅容纳本次 1033 个输入，不影响 DUT。

## 输入与预期结果

通过 DUT 的合法装载接口写入 1024 项 `../../silu/generated/silu_table.hex`；数值独立对照原 `silu_expected.hex`。前九个样本保持原中央 A/B/C/D 及旁路/地址边界，随后依次访问全部 1024 个表地址。地址零输入 raw=−2047，避免 raw=−2048 落入负尾旁路；其余地址 a 输入 `(a−512)×4`。表读回同时对照完整黄金输出及装载表值。

## 接受与冻结

事务在上升沿前以 valid && ready 计数和比对；在 NBA 及同步 RAM 响应稳定后核对冻结。快照包含 DUT 全部功能寄存器及输出，不包含随外部 ready 变化的组合连线。RAM 输出单独核对。合法表握手时必须 CEA=1；未完成装载或存在装载请求时不得开放输入。

| 沿 | E0 | E1 | E2 | E3 |
| --- | --- | --- | --- | --- |
| output_valid | 1 | 1 | 1 | 1 |
| output_ready | 0 | 0 | 0 | 1 |
| pipeline_enable 与 CEA | 0 | 0 | 0 | 1 |
| 控制及 RAM 输出 | 保持 | 保持 | 保持 | 同时推进 |
| 输出事务 | 不接受 | 不接受 | 不接受 | 接受首个等待事务 |

WaveDrom 图：[contract_freeze.svg](./contract_freeze.svg)，属于契约示意，不是仿真波形。真实逐拍记录在相应 CSV/WLF。

CSV 沿用旧测试台列名 `time_ns`，但 `%0t` 在 1 ps 精度下输出 ps 数值：相邻 10 ns 时钟周期增加 10000。因此读 CSV 时该列须除 1000 才是 ns，优先使用 cycle 字段定位；不改写原始 CSV。

## 通过条件与工具边界

候选必须 1033 接受/1033 输出、1024 合法表写检查、1024 表读回、所有冻结沿检查错误为零；排空后额外观察 12 拍，不能重复输出。原版固定负例预期 RAM 冻结错误和 raw=4 的错位。允许原版仿真进程退出 0，但明确 TB_FAIL 必须被报告为预期失败。

外部运行以 `run 2 ms` 设置仿真时间上限；没有预期结束 PASS 标志或未到规定数量都视为失败。1/64 拍为本轮新增关联覆盖，16/32 拍原向量回归另列。复位取消、错序装载和重载由既有全域测试台覆盖；不声称本关联测试覆盖它们。

原生规范生成器 `spec_document.py` 要求非空顶层 ports（接口校验行 463–477），与真实零端口 TB 不兼容。因此此伴随规格为人工契约加受治理 WaveDrom 渲染，不能宣称 canonical write-spec 成功；不加假端口、不修改生成器。原生严格门禁结果另存，功能通过不代表严格交付通过。
