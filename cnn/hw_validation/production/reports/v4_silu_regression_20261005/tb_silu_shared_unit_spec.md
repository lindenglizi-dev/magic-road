# tb_silu_shared_unit 冻结回归规格

本目录复用原生产测试台，将两条 readmemh 路径改为当前独立目录可解析的 `../../silu/generated/`，增加合法写使能和表无效期间旧输出泄漏监视器。原失败路径日志保留为无效测量。新增监视器发现地址零重复握手，进一步在 `drive_table_word` 改地址/数据后增加 1 ns 的测试台组合稳定等待，再检查 ready；DUT、黄金结果和原数值比较方式不变。最终完整结果使用 `candidate_full_domain_fixed.log`。

未修正采样竞争时监视器观察到 3073 次合法写入，初次地址零在相邻两个周期接受；严格的三次整表装载计数检查失败。修正后为 3072 次，未放宽预期数量。失败 `monitored`、定位 `audit` 与最终 `fixed` 日志分别保留。

原有测试包括错误首地址 fail-closed、1024 项完整装载、单输出三拍反压保持、pending 排空后重新装载、运行中复位取消、复位后完整重载及 65,536 个 INT16 输入对拍。观察到首次接受至首次可用输出为五个周期，连续无反压 II=1；这不是停顿期间也每拍完成。

推进与冻结周期图沿用 [contract_freeze.svg](./contract_freeze.svg)。真实零端口测试台不能用非空端口规范绕过校验；其人工伴随规格不代替严格门禁。1 ns 等待属于验证驱动的采样稳定时间，不是增加 DUT 流水或硬件延迟。
