# RoadYOLO 首批实施与物理对比报告

日期：2026-10-10。范围：获批P1A独立候选，PH1P35MDG324、速度等级−3、100 MHz。本文绑定本目录实际源码、仿真、TD数据库和报告，不覆盖旧基线。工程非Git仓库。

## 1 当前结论与仍未通过的部分

本次实际TD布局布线完成，报告中的内部setup、hold、recovery、removal均无负值。原参考的两条MAC DSP CE失败消失；新候选可作为后续代表层验证的内部时序候选，但不是生产交付版本。

仍未通过或待证：

- 外部接口15个setup、52个hold、5个removal失败端点，外部recovery无负值。窄口和外部复位尚无真实外设时序契约，未修改诊断延迟、引脚或增加例外。
- 源码严格门仍5,037错误/37严格警告，TB仍1,663错误/2严格警告。compile通过、parse错误0，不等于其余严格门闭合。
- SYN-5025全原语置零集合、一个未具名的generated-clock断主时钟告警、DSP/LSLICE dummy节点仍未完全解释。六个state_next查询PINS0/DRIVER0仅证明六个死对象，不证明全原语安全。
- 本壳不含56块ERAM的模型ROM、完整67层、真实DDR微循环、视频合并或检测后处理；真实QAT模型未接入，无精度或5 FPS通过结论。

全局位置：第一批四类证据已经形成，M2“存储与代表层”尚未完成。下一条必须单独决定的分支是ROM旧三轮修复预算耗尽后的新诊断授权，不需要为了这次内部正裕量再继续微调CE。

### 属性实际效果及局限

TD记录`max_fanout_keep=1`，综合网表保留`max_fanout=16`。读取本次`pr.db`查询到8份匹配复制网，各有1个driver，负载分别8、6、4、18、6、33、44、34；因此有真实复制/重分发，但并非所有实现网负载≤16。属性不是可保证的硬性布局扇出上限，不能虚报“扇出统一降至16”。

本次能确认的是：唯一RTL属性差异、同向量行为不变、映射/布线发生变化、全量报告内部均非负。不能从一次实现把所有裕量改善都精确归因于某个副本，亦不继续扫描阈值。

证据：`physical_comparison.json`、`physical_analysis.json`、`mapping_query/receipt.json`及`mapping_query/td.log`。只读数据库查询前后SHA256相同。`physical/pr.db`、构建约束、综合网表、布线网表、RAM/DSP端点和完整日志均保留。

## 5 整网预算及资源能否装下

本批修正预算见`budget/REPORT.md`和`budget/current_tile_budget.json`：67卷积（23DW/43PW/1Stem）、6个INT16原始头。

旧DW公式允许三点包跨4列tile，低估任务。down2 DW整层任务49,536→73,728；PW73,728。576个tile的实测小块周期乘法外推为DW630,720/PW340,992，非整层实测。另65层UNMEASURED，部分tile实际发射策略UNKNOWN。完整down2 DW物理乘法槽利用率25%。

仅把本壳与已有视频模板相加：8,038+12,358=20,396 Slice，距21,216余820；30+8=38 DSP，余2。数字只用于风险预警，既可能重复验证壳逻辑，也缺ROM和未来控制/后处理，不能作为合并后资源通过证据。

视频40 ERAM + 模型ROM预算56 + 本壳SiLU1 =97 ERAM，尚余11；ROM真实映射未证，额外tile/DMA/Top-K/CDC缓存仍需计入。当前2024 Distributed RAM LUT是新实测，`storage_review`中的2016/2040分别属于两个旧参考，不能混用。

存储审查指出halo需并行读取，不能直接搬进一块单口ERAM；若后续只试一个缓存，先评估384字节输出缓存同步读的1ERAM/64 DRAM-LUT权衡。此处只建议，未修改读延迟或缓存RTL。

## 6 参数包、DDR与必须取得的下一项决定

`storage_review/package_schema_check.json`已校验两包哈希、CRC、393个字段、7,168词及56份lane重建。schema1/2均140,522字节，但首个payload差异在432；pre/post字段含义不同，不能互换。当前目标schema2仍TEST_NOT_QAT，不是训练权重。

DDR五项均待匹配IP证据：地址单位；AW/W真实ready及时限；写后读可见性；返回容量/终止；复位取消后的晚返回。现桥缺WREADY完整传递、可见完成、RLAST等证明。不得用mock commit、固定N拍或推测`>>1`发布READY。

下一项需集中批准：

1. 在新独立ROM验证目录开启一轮有界修复与隔离TD诊断，旧427条失败及耗尽记录保留。
2. 使用schema2现成lane文件和官方40×512原语；先修/核查输出驱动、时钟边界和真实本地语义项，再逐字段读回、综合资源筛查。仅有映射正确且资源合理证据后才布局布线。
3. 不放宽严格交付门；若严格门未闭合，只在明确授权的隔离诊断范围获取实际56ERAM及初始化/端口证据，不称生产通过。
4. 并行准备Stem及12通道stride1 DW/PW的TEST向量和薄适配契约；不改冻结算术核、接口、II、复位或时序例外。ROM授权不包括真实DDR协议、训练、生产或上板。

未获该决定前，不启动ROM第四轮修复或TD。内部时序支线本轮就此收敛，不把内部正裕量变成继续微调壳的理由。

- `gate_compare_failure.json`：新脚本读取空path的Path(None)错误；脚本已修，不是RTL缺陷。

- 原参考、59端点反例、旧ROM/DDR失败、厂商网表端口警告全部保留；不通过删除告警、改验收或新增时序例外完成本批。

本批采用最小属性补丁和现成仿真/TD助手；没有重写调度平台或混入缓存迁移。相关数值、握手和真实物理验证保留，无关格式重写暂缓。
