# tb_rom_down2 验证契约

这是不可综合的单时钟测试台；实际顶层只有 `o_test_done` 输出，完成所有检查后置1并结束仿真。
内部 `clk` 周期10ns，复位和输入在下降沿改变；不模拟亚稳态或板级时序。

实例化 `road_rom_current_down2_top`；使用实际厂商ERAM仿真模型和冻结算术源码。
参数、SiLU表、三种halo及逐阶段期望值来自 `../reference.py`，由命令行传入绝对路径。
所有错误使用 `$fatal` 终止，成功标记 `TB_PASS_ROM_DOWN2`。

检查顺序：

1. 提前启动、装表中复位，旧参数与旧计算均不得泄漏。
2. 一项参数已保管后，阻塞真实计算装载边界80拍；地址、种类和数据保持，来源反压。
3. 最后表项已进入计算链表缓冲后，在SiLU叶接口阻塞80拍；不得提前开放halo。
4. 核对1676笔源接受、652笔参数实际提交、1024笔SiLU表实际提交。
5. interior、edge、bottom_right各跑正常和随机停顿，共6例。
6. 每例核对640项MAC、预重定标、SiLU、后重定标和写回，以及384项真实缓存导出。
7. 运行中、输出阻塞时复位；重新装满参数/表后，再跑正常恢复例，无旧结果。
8. 非法halo地址触发故障；12拍连续尝试装载、启动和导出不得重新开放。

周期采用核心busy窗口，须等于冻结调度器核心计数。
六类互斥优先级：外部提交阻塞→后处理/预留容量阻塞→提交→MAC接受→发射等待→排空/其他。
六类之和等于核心周期；这些分类不是各算子的独立忙周期，也不能据此把重叠活动求和。
boot、halo预装载、核心运行和输出导出分别记录；随机停顿用确定性LFSR。

相关接口时序图见 `../rtl/road_rom_current_down2_top_spec.md` 及 `../rtl/waveforms/`。
本说明不解除测试台严格格式/AST门禁失败；ModelSim实际通过与严格静态门禁分别保留。
