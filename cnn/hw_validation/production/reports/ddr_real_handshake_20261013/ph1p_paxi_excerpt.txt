2.3.2.2 AXI 地址至 pAXI 地址映射

     当用户选择使用 AXI4 接口时，MC 的 Interface Bridge 模块将 AXI4 接口总线的转换为 pAXI 接口
总线。由于 AXI4 总线的地址是字节地址，因此 axi_axaddr 信号的宽度取决于用户在“DDR Solution
Configuration”一栏中所设置的“DQ Bytes”值。axi_axaddr 至 paxi_axaddr 存在如下表所示的映射
关系。

                                      表 2-17 axi_axaddr 至 paxi_axaddr 的映射关系

    DQ Bytes * 8                                                AXI Byte Address
               64                               axi_axaddr = paxi_axddr[MC_ADDR_WIDTH-1:0]
               128                        axi_axaddr = { paxi_axddr[MC_ADDR_WIDTH-1:0] , 1’b0 }
               256                        axi_axaddr = { paxi_axddr[MC_ADDR_WIDTH-1:0] , 2’b00 }
               512                        axi_axaddr = { paxi_axddr[MC_ADDR_WIDTH-1:0] , 3’b000 }
