## 本次完成什么

独立目录：`cnn/hw_validation/production/reports/dynamic_postprocess_function_20261008/`。

核心代码：`road_dynamic_postprocess.v`。保留 MAC、舍入与 SiLU 核源码，复用前批动态重定标核，增加三路原子参数捕获、有效路选择、激活/预测分流、INT8 饱和和完整批次结果导出。

```text
三路 INT32 + 三路 pre 参数 + 单层 post 参数 + mask/tags/mode
             ↓ 一批寄存暂存
        按有效 lane 逐路处理
             ↓ 动态 pre → INT16
       ┌─────┴──────────────┐
   激活特征模式          预测头模式
      SiLU                直接保留 INT16
   动态 post
   饱和 INT8
       └─────┬──────────────┘
       全部有效路计算完成
             ↓ 缓存三个结果
       按 lane 顺序握手导出
```

采用一套重定标核先后完成 pre/post，避免在功能诊断期复制算术模块；不新增通用 FIFO、参数 RAM 或外设。该简化的代价是串行延迟，不把它包装成吞吐优化。旧 MAC 的内部 II 没有变化，但新批次接口只有空闲且装表完成才 ready，不能把 MAC 的 II=1 当成此顶层的批次 II。

## 模块接口与握手

- 输入：三路 INT32 累加值、三路非负 INT32 pre multiplier、三路 6-bit shift、单层 post multiplier/shift、激活模式、三路 mask、三个 opaque 16-bit tag、MAC 原子故障。
- 数据与参数只在 `i_input_valid && o_input_ready` 捕获；之后更改输入端口不影响当前批次。
- 输出：16-bit 数据、16-bit tag、类型位；激活数据为 signed INT8 的符号扩展，预测头保留 signed INT16。下游应按类型分别写一字节或两字节。本批尚未实现 DDR writer。
- 每批所有有效路算完才发布首个结果。输出等待 ready 时数据、tag、类型和 valid 保持。
- 接受批次前核验全部有效路，第三路非法也不能先导出前两路。mask=0、负系数、shift63、输入 MAC fault 等锁故障直到复位；旁路模式忽略 post 参数，未使能 lane 忽略其 pre 参数。
- 异步复位取消在途事务。释放同步由调用者负责；复位后必须重新顺序装载 1024 项表，未装完前两种模式均禁止计算。没有假定 RAM 清零或初始化。
- tag 只是本批不透明身份，不是整网 DDR 地址或帧编号；完整图的地址和帧元数据仍由后续调度器持有。

接口规格和压缩示意周期图已由技能工具生成：`spec/dynamic_postprocess/road_dynamic_postprocess_spec.md` 及 `waveforms/road_dynamic_postprocess_atomic-batch.svg`。图不是实测波形，也不表示计算区只有一拍。

## 数值与功能证据

Python 直接复用工程 `cnn/integer.py` 的 `requantize/silu/tables`，没有另建浮点推理替代部署算法。共 330 批、604 个有效输出，覆盖 mask 1..7、极值、负数、中点、SiLU 尾部与上端点、动态系数和激活/原始预测交替。

`simulation_checked.log`：

```text
NUMERIC_PASS batches=330 outputs=604 core_cycles=15388 raw=4731 activated=10657
TB_PASS_DYNAMIC_POSTPROCESS reset_stages=8 partial_table=1 atomic_faults=6 recovery=1 table_fault=1
```

Icarus 编译与 vvp 运行实际退出 0；`results.csv` 的 604 行由 Python 再次逐项与整数参考比较，完全相等。

附加回归：

- 输入接受后故意改变全部输入参数，核对仍使用已缓存内容。
- 随机输出背压及每 17 批一次 64 拍保持检查；批次缓存占用时尝试新输入，ready 必须为 0。
- 8 个活动状态逐一复位，立即撤销 ready/valid，释放后检查 50 拍无旧结果和装表前误启动。
- 装表中复位，整表重新装载。
- 6 类批次故障：MAC fault、第三路非法 shift、第三路负 multiplier、非法 post shift、负 post multiplier、空 mask。每类 80 拍检查无结果、拒绝新输入、故障锁存。
- 恢复后真正提交一个新的 INT16 结果，再检查无重复；无效 lane 的坏参数和旁路模式的坏 post 参数正确被忽略。
- 非顺序装表触发故障，复位并重装后恢复。

15,388 拍是这批混合、随机背压向量的输入接受至最后输出确认窗口之和，不含装表、不代表层或全帧。raw/activated 两类窗口互斥可相加，不是各算术模块的重叠忙周期。没有用它与旧 4×4 DW/PW 的 3,257 拍比较或宣称加速。
