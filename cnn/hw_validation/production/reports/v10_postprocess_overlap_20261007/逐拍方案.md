## 既有各级能力

以下边沿均指上升沿：接受边沿为 t，NBA 更新后的 valid 为“有效”，下一上升沿才是下游“接收”。停顿会增加实际经过时间。

| 级 | 核本身延迟 | 无停顿 II | 既有共享与握手 | 反压响应 |
|---|---|---|---|---|
| MAC | last 接受 L，L+9 后 valid，最早 L+10 接收 | 同一归约内 1；不同归约受终态握手限制 | 24 乘法器，三个 INT32 输出一次提交 | result 不 ready 则保持；last 接受后禁止下一任务 |
| 前重定标 | 9 个使能寄存级；t+8 后 valid | 1 个 advance | 旧调度与后重定标共用一实例，逐项等待 | advance=0 当沿冻结全部数据、valid、tag、fault |
| SiLU | 6 个使能寄存级；t+5 后 valid | 1 | 一块 1024 项表；input/output ready-valid；无 tag 端口 | output valid 且 ready=0 时，当沿冻结全流水及 RAM CE；输出未出现前可继续填入剩余级 |
| 后重定标 | 同前重定标 | 1 | 旧调度共用前级实例 | 同前级 |
| INT8 饱和/写回 | 组合饱和，真实写回握手边沿提交 | 1 | 旧调度另设写状态 | 新调度由最终 ready 控制，阻塞时数值与地址保持 |

旧调度每项前重定标 10、SiLU 7、后重定标 10 周期是控制器占用，并非各核的固有 II。v9 的 DW11008、PW12929、组合23937 为旧串行调度实测；其物理资源仅包含旧低 I/O 壳，不包括本轮层调度器。

## 最小候选与资源取舍

采用两个**原样**重定标实例，分别前/后；仍共用一个原样 SiLU。选择多一个重定标流水来避免单实例回流仲裁，以换取单路 II=1。实际面积及固定系数折叠由新综合核查，不把它当通用动态系数成本。

MAC 三输出进入两项整组结果队列。PW 各组 alpha/beta/gamma 在连续三拍进入前级，DW 只送有意义的选中路。队列同时保存 layer、position、channel、lane 身份；固定系数跟随实际 lane，而不是当前 MAC 调度状态。每组故障不送任何路。故障停止整 tile 发布，恢复需外部复位及完整重装表。

前级和后级都用原 16-bit tag。SiLU 前后用 8 项元数据 FIFO，以实际输入握手 push、实际输出握手 pop；六级 SiLU 最多六个未交付值，8 项容纳计数满值，不能用原始时钟移位代替握手。复位取消所有队列和在途身份，不清 RAM 内容，只清有效状态。

反压逻辑：`post_advance = !post_valid || final_ready`；SiLU 输出接收许可取 post_advance 和合法元数据；`pre_advance = !pre_valid || silu_input_accept_possible`。因此有效尾级受阻时同沿停止向下游的承诺，上游可以填完尚空流水级和结果队列，容量满后整组 ready 撤销，不越容量接收。响应不依赖任意固定等待；TB 必须测首次阻塞至入口撤销的实际最长边沿间隔，并区分“允许填空级”与错误迟到握手。

## 无停顿逐拍

以第一路进入前重定标的边沿为 t=0：

| 边沿 | 第一项动作 | 第二/第三项 |
|---|---|---|
| 0 | 前级接受 alpha | — |
| 1 | 前级第二寄存级 | 前级接受 beta |
| 2 | 前级第三寄存级 | 前级接受 gamma；beta 推进 |
| 8 后 | alpha 前级 valid/data/tag 稳定 | beta/gamma 在后续级 |
| 9 | SiLU 接受 alpha，元数据 push | beta 前级 valid |
| 10、11 | SiLU 接受 beta、gamma | 前级继续接收下一组（有数据时） |
| 14 后 | alpha SiLU valid | metadata 队首仍为 alpha |
| 15 | 后级接受 alpha，元数据 pop | beta SiLU valid |
| 16、17 | 后级接受 beta、gamma | SiLU/前级并行运行 |
| 23 后 | alpha 后级 valid，INT8 饱和结果及 tag 稳定 | beta/gamma 后级推进 |
| 24 | alpha 特征写回 | beta 后级 valid |
| 25、26 | beta/gamma 特征写回 | 与上游各级重叠 |

23 是第一项接受到最终 valid 的边沿差，24 是到写回握手的边沿差；不是三路每项24周期串行执行。加入队列、控制或层切换后以实际端点计数为准。

## 验证与计时

先 Python 参考和结构化评审，再 RTL。复跑原 MAC、算术、SiLU、层回归，补连续/气泡/长反压/队列满/每级复位/末组故障/系数路切换。逐级对比以 tag 寻址，不假设跨级调试事件仍串行排序；不能因 X 值或缺文件比较而假通过。

核心总周期从 start 接受到最后有效写回/完成，预装载、导出各单列。各核忙周期可以重叠，报告事件计数、占用与重叠，不求和作总周期。停顿用优先级互斥分类，另报告起止边沿及覆盖。相同完整 DW/PW 向量比较，不用故障早退算加速。

新物理顶层必须包含动态输入存储、DW/PW runner、MAC、两级 round、SiLU RAM、队列、元数据与写回、真实输出读回及窄口壳。不能沿用旧壳资源。PH1P35MDG324 −3，100MHz，无新增时序例外，外部窄口/复位的未签核问题如实保留。
