# DW 与 PW 小块数值和调度自检

无端口仿真顶层。四套冻结测试参数、三个空间位置，每套 10 个完整输出场景。每个场景比较 640 个 MAC、预重定标、SiLU、后重定标和提交值，导出 384 个字节；随机反压使用核心起点一致的种子。检查输入与提交负载在握手前保持、队列排空、PW 四种位置复位、256 拍提交反压、末路 INT32 原子故障与禁止半块发布、参数完整性和非法参数拒绝。

无反压完整核心窗口为 2,607 拍，DW 2,015、PW 592；预装表、载入和导出另计。八类互斥周期总和须等于核心端点周期；算子忙周期可重叠，不相加作为总周期。

协议周期图：[PW 连续任务](../rtl/waveforms/down2_dynamic_tile_runner_pw_task_stream.svg)。旧基线同一 TB 为 3,204 拍，不要求两版可见延迟相同。
