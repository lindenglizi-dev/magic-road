# v7低I/O物理网表独立结构审查

## 结论

对冻结低I/O验证壳的综合网表和布局布线后网表进行只读结构核查后，未发现24路动态INT8乘法、动态偏置、固定系数重定标、SiLU表或真实特征缓存被综合删除或替换为编译期数据常量的证据。

本结论的状态为 **`STRUCTURE_PRESENT_WARNING_UNCLOSED`**：允许把该实现作为隔离物理基线继续分析，但不把“结构仍在”泛化成全流程通过，也不等价于逻辑等价验证、门级功能仿真、生产交付或时序收敛。TD的`SYN-5025 WARNING: Using 0 for all undriven pins and nets`原样保留，未被豁免；本报告只证明下列关键动态路径在两个网表中仍实际存在。

## 24路动态MAC

- 综合报告识别出24个`8x8`乘法宏和一个重定标用`32x32`乘法宏。
- 门级和布局布线后网表中都保留24组位于`road_mac_probe_Inst_chain/mult0..mult23`层级的`PH1P_PHY_DSPSIOU_V2`与`PH1P_PHY_DSPMULT_V2`。
- 24组均配置为有符号`DUAL_9X9`乘法。每组`.xa`连接`reg_activation_front_b`的动态8位值，每组`.y`连接`reg_weight_front_b`的动态8位值；不存在把操作数整体接为常量的实例。
- 三个输出通道分别复用同一组八个激活字节；权重端覆盖三个通道的24个不同字节。布局布线会复制激活符号位网络，例如`reg_activation_front_b[7]_dup_3`，这仍由动态包读出及握手逻辑驱动，不是常量零。
- 动态96位偏置仍完整保留。门级网表有0到95共96个`reg_bias_front_b`驱动位，并通过`flag_first_front`选择进入99位带符号扩展的`reg_base_product`；布局布线后网表仍引用全部96个偏置位。

因此，本轮物理结果确实包含24条动态`8x8`乘法数据路径，不能解释为常量测试向量被折叠后的空壳。

## 固定系数重定标

冻结契约的前重定标系数为甲/乙/丙通道`1/3/5`，SiLU后系数为`1`。系数不是低I/O顶层的动态输入。

网表保留一个逻辑`32x32`有符号乘法宏；物理映射使用额外2个`PH1P_PHY_DSPMULT_V2`、2个`PH1P_PHY_DSPSIOU_V2`和1个`PH1P_PHY_DSPTADD`。乘数值端连接动态`reg_multiplier_value_b[31:0]`，系数端已被合法化简为由阶段和通道选择的低位模式。该结果只代表当前固定系数集合的真实实现成本，**不能代表通用动态32位系数乘法器成本**。

## SiLU表和缓存

### SiLU表

- 逻辑1024项×16位表实现为1个`PH1P_PHY_ERAM_V2`，资源报告为1块ERAM20K。
- `addra`连接动态表/查询地址，`dia`连接动态16位表数据，`wea`连接`flag_table_write_enable`，片选连接真实流水许可。
- 表内容没有被固化成初始化常量；复位后仍依赖协议重新装载完整1024项后才允许计算。

### 包缓存和特征缓存

| 存储 | 物理实现 | 数量 | 结论 |
|---|---:|---:|---|
| 96包控制字段first/last/mask | 分布式RAM | 4个DRAM hard controller，32个DRAM LUT | 非FF缓存 |
| 96包×64位激活 | 分布式RAM | 16个controller，128个DRAM LUT | 非FF缓存 |
| 96包×192位权重 | 分布式RAM | 48个controller，384个DRAM LUT | 非FF缓存 |
| 96包×96位偏置 | 分布式RAM | 24个controller，192个DRAM LUT | 非FF缓存 |

合计93个`PH1P_PHY_DRAMHARDCON`和744个DRAM LUT，其中验证壳包缓存占736个，计算链特征缓存占8个。特征缓存的12位有效标志仍是复位可清的寄存器；缓存内容本身不依赖复位清零。

门级和布局布线后网表的93个DRAM controller全部保留动态写地址和非恒零`.we`。它们的`.wrst`均为`1'b0`，对应源RTL“不复位RAM内容、复位有效位/协议状态”的设计，而不是把写使能或数据通路归零。SiLU ERAM的地址、数据和写使能也均为动态网络。

## `SYN-5025`和悬空节点核查

TD警告原文为：

```text
SYN-5025 WARNING: Using 0 for all undriven pins and nets
```

`check_timing_verbose.rpt`把悬空对象归到两类：

1. 26个`PH1P_PHY_DSPSIOU_V2`宏各有`mul9_mode`和`mul9_signed`，共52个模式端点；
2. SiLU `flag_round_odd_reg_syn_3`所在LSLICE未使用的1个`ofa`输出。实际奇偶标志使用同一slice的寄存输出`oqa`。

两个网表中，24路MAC的动态`.xa/.y`、动态偏置选择、93个DRAM写使能/地址、SiLU ERAM地址/数据/写使能、特征缓存读写及缓存有效位均仍存在，未发现这些关键网络被`SYN-5025`替换为零。模式端点和未使用LUT输出不能据此解释成MAC数据端或RAM控制端被清零。

但结构查看不是形式等价，也未运行布局布线后网表功能仿真。因此`SYN-5025`仍作为未完全闭合的工具风险保留；本报告不把它改写为“无警告”或生产可签核。

## 严格检查器重点分类

冻结壳的667条严格诊断仍真实保留，未因TD成功而清零。对本轮要求重点核查的三组，结论如下：

- `VG125`共56条，均针对显式定宽字面量不是“最小位宽”，例如`6'd24`、`9'd192`和与计数器同宽的`32'd1`。这些写法本身未造成截断；24组和192项比较正是用扩展候选值对同宽阈值守卫。
- `VG122`共15条，均为同宽计数器加同宽`1`的静态规则报告。人工核查确认有界功能计数器受协议范围保护：表项最多1024、负载字22、包96、位置4、运行索引96、导出地址12、STATUS响应18字且索引为0到17；组/项使用扩展后的候选值在写入前检查24/192。32位诊断计数器理论上仍会在`2^32`事件后回绕，这是保留的范围边界，不能写成无限计数。
- `VG098`共16条，覆盖全部16个状态符号。独立周期trace实际观察到状态编码0到15全部出现，因此这些不是“已确认不可达状态”；这是检查器未完成形式可达性证明。该动态覆盖也不是全路径形式证明，故规则仍保持失败。

`VG104`组合环和`VG141`多驱动在单壳规则统计中均为0 finding；这只说明对应检查未报具体实例，不豁免AST、driver/source closure、原计算链374条诊断或其余严格门失败。

人工文档更正记录：早期报告把“16个FSM状态”误写成“16个STATUS输出字”。冻结RTL实际定义`STATUS_LAST_INDEX = 17`，因此响应为索引0到17共18字；本更正只修改review文档和机器记录，未改RTL、网表或物理结果。
