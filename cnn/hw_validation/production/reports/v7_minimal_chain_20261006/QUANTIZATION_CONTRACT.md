# 最小计算链测试量化与接口契约

用途为硬件验证测试，不使用训练权重，不作为识别精度证据。当前状态：数值参考可执行；累加溢出契约冲突待决定，联合RTL未生成。

## 数据格式和单位

| 数值 | 位宽和单位 | 测试参数 |
|---|---|---|
| 输入 | signed INT8，按张量 scale，zero-point=0 | scale=1/16 |
| 权重 | signed INT8，按输出通道 scale，zero-point=0 | scale=[1/16,3/64,5/256] |
| 偏置 | signed INT32，单位为输入scale乘该输出通道权重scale | 只在位置首组加入一次 |
| 分组点积 | 8输入乘3输出，每lane signed INT8×INT8 | 非有效lane由mask屏蔽，不能依赖其内容为零 |
| 中间累加 | 部署契约候选signed33；旧核保存signed32 | 冲突未解决，保留两种结论 |
| 最终累加 | signed INT32，三通道任一越界则取消该位置正常输出 | 不回绕，故障负载全零，不能发布成功 |
| SiLU前乘积 | signed INT64，完整累加值乘非负INT32 | M=[1,3,5]，shift=[0,2,4] |
| SiLU输入输出 | signed INT16，单位1/256，即Q7.8 | round最近偶数，输入饱和[-32768,32767] |
| SiLU后乘积 | signed INT64，SiLU整数值乘非负INT32 | M=1，shift=4 |
| 特征缓存 | signed INT8，按张量scale，zero-point=0 | scale=1/16，饱和[-128,127] |

前比例严格满足 `M/2^shift = input_scale * weight_scale / (1/256)`；后比例满足 `M/2^shift = (1/256) / output_scale`，参考入口用有理数逐项断言，不把移位误认为完整重定标乘法。非零zero-point直接拒绝，尚未实现偏置修正，不声称支持非对称量化。

真实SiLU表从v4冻结1024项表复制，SHA256为 `05d6d7062a6b6d0c9178562168d7f8e1554182bb99878b85a0cb6faeb71a25a6`。地址是最近偶数舍入(input/4)+512；负尾input≤-2048输出0，正尾input≥2048恒等，中央地址1024输出常量2047。人工地址减512的表只保留生成器快照，不参与数值参考。

`road_round_shift`只接收已有signed64乘积，不完成乘法。shift=63和INT64_MIN属于该核故障输入；部署允许shift=0..62，合法INT32乘非负INT32不会产生INT64_MIN。联合链仍需实际实现和验证乘法，不能省略后声称重定标完成。

## 位置和组契约

基础形状2×2×16，1×1卷积，3输出通道。每位置两组8输入，first仅第一组为1，last仅第二组为1；每位置只加一次bias。基础有效MAC=192，12个输出，按HWC地址 `position*3+output_channel` 写入0..11。

尾组用例2×2×13，第二组mask=0x1f。无效激活lane故意填127、权重填-128，漏mask必然影响结果。有效MAC=156，物理已安排乘法lane仍为192，理论lane利用率81.25%，不是端到端吞吐测量。

## 尚未实施的联合接口要求

所有联合模块计划同一100 MHz时钟，保留原异步低有效取消复位，不擅自更改释放协议。请求仅valid与ready同时成立才接收；未接收时保持data、first/last、mask和位置身份；输出受阻时valid、data和fault保持。故障与正常结果分开解释，禁止把fault全零负载作为成功特征写回。

SiLU没有tag端口，联合适配层必须维护位置与通道身份，并在接收、流水推进、反压和取消时与数值同步。初版可以串行保证单事务身份，但这不是性能候选。round依赖共同advance，不能只冻结valid而继续推进data。

输出须完成真实片上写入，再由读口返回对拍；完成事件是最后读回结果被消费，不是最后MAC完成。复位取消在途事务及未发布结果，重新装载真实表后才接新任务。上述联合协议尚未经过RTL仿真，不记为通过。

## 待决定的唯一前置冲突

部署契约要求部分和可在signed33范围内暂时超INT32，只在最终检查；旧MAC和其Python参考每一组均检查INT32，且非末组也会发布故障。不能只改Python期望而复用旧核。

建议按已冻结部署契约制作独立MAC候选：扩展跨组累加存储，最终才判INT32，保留三路原子故障、first/last、反压和复位语义。该修改属于行为调整，需用户确认后执行；不覆盖旧核，不改变SiLU，不预先承诺时序或II改善。
