1 概述

   本手册主要介绍 SALPHOENIX®1A（以下简称 PH1A）系列 FPGA 的 DDR3/4 接口功能，描述 IP Core 的
核心架构、提供定制 IP 的流程和使用细节。该手册适用于 PH1A400、PH1A180 和 PH1A90。


1.1 特性与规格

1.1.1 DDR4

         Supports configurable data bus width from 8bits to 72bits with increment of 8bits
          for SDRAM.

         Supports 8:1 mode (BL8 only).

         Supports max 3 HPIO Banks, max 72bits DQ usage.

         Supports hard Programmable PHY Controller (PPC).

         Supports x8 or x16 memory device types.

         Supports ODT calibration and dynamic enable and disable.

         Supports ZQ for HPIOs.

         Supports slew-rate control for output driver.

         Supports optional internal VREF calibration for optimum data reception.

         Supports mounted SDRAMs with fly-by topology.

         Supports DDR PHY Interface（DFI） 3.1.

         Supports maximum 2 Ranks for hard PPC.

         Supports 2T mode.

         Supports background delay line calibration and VT compensation.

         Supports write data mask, write DBI and read DBI.

         Supports Built-in-self-test (BIST) loopback.

         Supports DDR4 Ping-Pong PHY (Shared-AC mode).

         Supports PHY initialization and Write leveling, Gate training, Read data eye
          training, Write data eye training, Vref training.

         Support DDR4 MPR reads when PPC access mode only.

1.2 系统解决方案

   本 IP 支持 DRAM 标准协议 JESD79-3F（DDR3 SDRAM Standard）和 JESD79-4（DDR4 SDRAM Standard），
提供 3 种工作模式：Standard PHY、Ping-Pong PHY 以及 Memory Cnotroller and Standard PHY。其
中，Standard PHY 模式支持的位宽范围为 8-72 bit DQ，以 8 的倍数递增；Ping-Pong PHY 支持数据位
宽为 8、16 和 32 bit DQ。上述两种模式均提供标准的 DFI 接口与用户逻辑对接。MC and Standard PHY
模式在 Standard PHY 模式的基础上增加了 Memory Controller 功能，支持 AXI4 和 pAXI 接口与用户逻
                                              ，pAXI 接口支持用户端
辑对接，其中 AXI4 支持用户端的数据位宽最高 512bit（对应颗粒端 64bit DQ）
                            。
数据最大位宽 576bit（对应颗粒端 72bit DQ）

   本 IP 支持双控制器应用，双控制器的数据位宽总和最大为 64bits（即可设为 x32+x32 或 x16+x48，
                      。双控制器的应用，可通过例化两个 IP Core 实现。
其中 x32+x32 需要共享 Bank32）

   顺序写数据：递增地址下写数据，burst 长度为 128，进行 64 次写 burst 操作。

   顺序读数据：递增地址下读数据，burst 长度为 128，进行 64 次读 burst 操作。

   非跨行混合长突发读写：对 DDR 颗粒的某一行中进行地址递增的数据写和读操作，每次写和读的

   跨行混合长突发读写：对 DDR 颗粒的不同行地址进行数据的写和读操作，每次写和读的 burst 长度
为 64，进行 64 次读写 burst 操作。

   非跨行混合短突发读写：在 DDR 颗粒的某一行中进行地址递增的数据写和读操作，每次写和读的
burst 长度为 4，进行 1024 次读写 burst 操作。

   跨行混合短突发读写：对 DDR 颗粒的不同行地址进行的数据写和读操作，每次写和读的 burst 长度
为 4，进行 1024 次读写 burst 操作。

   随机地址混合读写：进行随机地址的数据写和读操作，每次 burst 的长度为 2，进行 1024 次读写
burst 操作。

2 IP 使用

2.1 定制化 IP 工程步骤

2.1.1 新建 DDR SDRAM IP

   以 TD6.2 为例，不同的软件版本可能有差异，请参考对应版本的数据手册。

   打开 TD 软件，点击 Tool -> IP Catalog->DDR3/4 SDRAM，设置完 IP 的 Export Path 和 Component
Name 后，显示如图 2-1 所示的 IP Generator 界面。其中，Component Name 为用户设置的 IP 名，用户
可在 IP 配置过程中随时修改此名称；External Memory Interface 包括 General、PHY Controller
Option、Memory Option、IO Planning 和 Summary 5 个界面。

2.1.5.1 IO 管脚分配规则

   一个 HP Bank 共 50 个管脚，包含 4 个 Byte Group（其中两个 2 个 N12 管脚）
                                                        ，其中每个 Byte Group
包含一对固定位置的专用 DQS 管脚、5 对差分管脚（可分配为 DQ 或 DM/DBI）。另外有 2 个 Byte Group
各包含一个单端管脚。IO 分配遵循一个 DQ Byte 对应一个 Byte Group，具体的 IO 分配规则为：

         当使用 X8 或者 X16 的器件时，DQS 信号必须分配在每个 Byte Group 专用的时钟管脚 DQS 引脚
          上,并且和 DQS 对应的 DQ 信号和 DM/DBI 信号也必须分配在同一个 Byte Group 中。

         CK 必须连接到 PN 对上，可以是任意的 PN 对。

         地址/控制信号必须放在同一个 Bank 内。

         如果一个应用使用 3 个 Banks，地址/控制信号推荐分配在中间的 Bank32。

         单个 AC 的低频信号(reset_n/cke/odt/parity/alert)可以放置在 DQ 组内。

                                                      ®

         Vref 放置在专用的 IO 管脚上，使用内部参考电压时，Vref 管脚可作普通 IO 使用。

         两个 DDR 控制器可以共用 3 个 HP Banks：每个 Byte Group 专用，控制器之间的 Byte Group
          不能交叉使用。当两个 DDR 控制器需要共享中间的 Bank32 时，只允许两个控制器的 DQ Byte
          分配到 Bank32。

         DCI 级联使用时，主 Bank 的 VRP 接参考电阻(240 欧)到地，从 Bank 的 VRP 可用作普通 IO，也
          可以接参考电阻（240 欧）到地。

3.2 PPC

   PPC 为 MCU 控制下的可编程 PHY 控制器，该控制器可以在 MCU 控制下完成 DDR 初始化、训练、内环
和外环测试以及 DRAM 数据读写测试。同时该模块面向用户开放 DFI 接口。

                                              （Single Data Rate）
   DFI 接口用于实现外部控制器和 DDR PHY 之间的数据转换。数据速率固定为 SDR
模式。详细内容请参考 3.6 章节。

   PPC 需要两个时钟：工作时钟（ctrl_clk）和配置时钟（apb_clk）。工作时钟与 DFI 总线时钟 dfi_clk
相同，是存储器时钟频率的 1/4。


3.3 DDR BANK

   DDR Bank 由 4 个 DQS Byte Group 和 1 个 PZQ 模块组成。PZQ 完成 Vref 和 ODT 的控制。DQS Byte
Group 主要完成读写 DQS 信号的产生，以及 IO 控制信号的产生。


3.4 DDR PAD

   DDR PAD 为模数混合模块，由 IOL 和 IOB 组成。IOL 包括 IFIFO、OFIFO、ISERDES、OSERDES、IDELAY
                                          。
和 ODELAY。IOB 完成数据输入输出的使能控制（具体参考 HPIO 的用户手册）

   数据路径具有 SDR 和 DDR 两种模式，信号方向可配置为仅输出、仅输入或双向。对于 DDR 存储器应
用，AC 通路配置为 SDR 输出模式，而 DQ 通路配置为 DDR 双向模式。

   对于存储器应用，AC 管脚包括时钟、地址和命令，最多占用 4 个 Byte Group，管脚数量取决于存
储器的容量大小和支持的列数。DQ 管脚以 Byte Group 为单位，占用的 Byte Group 数量取决于所需的
数据宽度。例如 32 位宽的数据，则需要 4 组 Byte Group；64 位或 72 位宽数据，则分别需要 8 组或 9
组。

3.7 Memory Controller

   Memory Controller 的内部架构如下图所示，其主要由 Interface Bridge、MC Core 和 DFI-Retiming

DFI 信号，实现与 PHY 端的连接。使用 MC 可以有效提高数据总线效率。

   由于 IP 的宏定义和 module 定义的作用域为全局作用域，在双控制器应用时需避免两个 IP 中宏定
义和 module 定义的重复，因此 TD 产生两个 DDR IP 时，用户需通过设置“Controller Index”进行区
分。

   PH1A 系列的 FPGA 中，每个 HP BANK 的阻抗校准、阻抗配置和 Vref 配置，均通过同一个 DDR_BANK
实现，因此当两个 DDR IP 存在共享 BANK32 的情况时，该 BANK 的阻抗校准、阻抗配置和 Vref 配置需要
通过其中一个 IP 进行控制。在本 IP 实现中，该控制由 Controller Index 为 2-1 的 IP 完成。

   在 PH1A 系列 FPGA DDR 双控制器应用中，存在两种情况：1. 两 IP 共享 BANK32；2.两 IP 相互独
立，即非共享 BANK32。


4.2.1 非共享 BANK

   用户使用的 2 个控制器为非共享 BANK 情况时，两个 IP 的 Multi-Controller 和 Controller Index
