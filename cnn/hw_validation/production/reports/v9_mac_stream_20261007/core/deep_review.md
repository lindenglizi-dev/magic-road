# road_mac_probe II=1 预实现深审

| 项目 | 审查结论 | 主要风险与控制 |
|---|---|---|
| 接口 | 同名同端口、无参数变化 | 不为验证增加端口；内部层级信号供 TB 只读观察 |
| 复位 | 异步低有效，ready 复位值保持 1 | 清除所有 valid/last/final 对齐位，避免复位后幽灵结果 |
| 时序/流水 | A0-A5 数值流水，A6-A9 仅末组终态对齐 | 每级元数据必须与数据同拍；last 到 valid 固定 9 周期 |
| 握手 | 序列内 II=1；last 后关输入；结果握手后重开 | 同拍 last 接受优先关闭，输出握手不能在 ready 尚为 0 时误接下一任务 |
| 位宽/符号 | 16/17/18/19/33/34 位真实贯穿 | 所有加法显式符号扩展；不能只改 ready 而保留旧前端 base 快照 |
| fault | 仅末组按 INT32 检查；任一路 fault 三路归零 | 非末组不新增长程溢出协议；故障末组禁止写回 |
| 综合 | 24 个乘法器与有限加法树，无队列 | 反馈仅为 A5 的 signed33 寄存器加法；实际 Fmax 留给独立物理闭环 |
| 测试覆盖 | 正负极值、mask、空泡、连续 24 组、first0/first1、背压、reset | 功能仿真不等价于布局布线或全链吞吐结论 |

结论：在单序列、last 后禁止新任务的合同下，反馈相关距离为一个周期，II=1 不要求多上下文，且可用 A6-A9 对齐保持外部 9 周期延迟。实现风险集中在 A5 同拍旧值读取/新值写回和末组 fault 对齐，需由 Python 与 RTL 波形同时验证。
