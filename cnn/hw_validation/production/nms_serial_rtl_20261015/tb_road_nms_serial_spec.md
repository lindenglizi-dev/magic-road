# tb_road_nms_serial 测试台规格

本模块没有外部端口，不综合。`tb_spec.json` 为完整意图合同。受管 write-spec 对空 ports 返回 `modules[0].interfaces.ports must be non-empty`，因此本伴随文档为人工补充，不能标记为受管规格门通过；不为迁就文档工具新增虚假端口。

时钟 100 MHz，复位低有效。候选表来自 16 组基础 Python 参考和2组独立附加向量；服务端一次只承接一个读，支持请求反压、响应延迟。所有最终条目、面积/交集/抑制判定及保留/过滤决定逐项对拍。

正常情况下先接收 sealed，再响应 class/index，最后消费 FINAL97。仅当完整结果条目全部接受才允许 done；不允许第二个未决读。scoreboard 验证握手前请求与输出稳定、输出无丢失/重复。

取消与复位同时清 DUT、服务未决响应和临时结果。错误记录必须产生粘滞 fault、禁止 done，并清完整表有效性。用例包含已有条目后出错、第二条目在 valid/!ready 时取消，以及恢复后从头重跑，不能把故障早退当吞吐。

54 个计划运行：18 向量各正常/随机一次，9 个故障输入与恢复，8 个取消/复位位置与恢复，1 个128拍长输出反压成功导出。实际通过情况以最终runs/summary.json为准。

周期窗口从 sealed 接受之后的第一拍到 done 被采样；请求阶段、响应阶段、输出阶段、乘法阶段、其他控制互斥且和等于端点周期。额外列出真正未握手的 stall 子计数；该子计数不可再次相加。

周期示意使用同目录 `spec/nms_serial/waveforms/tb_road_nms_serial_read_pause.svg`；该图由受管 WaveDrom 渲染器单独生成，不代表端口交叉检查通过。
