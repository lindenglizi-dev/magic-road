# tb_road_result_publish_joint testbench contract

This portless, non-synthesizable top uses 100 MHz source and 75 MHz destination clocks. Common asynchronous reset cancels the complete instantiated chain. The template SOF is the first active pixel every 1650 x 750 = 1,237,500 destination cycles (16.5 ms), with the first pulse one complete period after reset release.

The destination clock uses rounded half-periods6.667/6.666/6.667ns, totaling20ns per three half-periods, so its average is exactly75MHz at1ps simulation precision. SOF is a periodic first-active-pixel event with explicit arbitrary phase; the testbench does not recreate the full horizontal/vertical timing generator.

The complete 12096-cell HEAD112 stream traverses the frozen true-G10 56-lane PH1P ROM reader, shared LUT, TopK internal candidate RAM, NMS, new publisher and C8 source/pending/active tables. Every accepted FINAL97 word is compared with the frozen golden result and every active97-bit word is checked again after SOF; reads outside count return zero. The expected_words testbench array is solely a golden store and does not create a fourth functional table.

The publisher owns pipeline start/cancel. Start locks epoch, task, source frame, model and same-source capture timestamp; context inputs deliberately change while busy. NMS task identity, output count and source completion time form the exact265-bit expected metadata. Last entry and metadata acceptance must occur on different cycles. Metadata must remain valid and stable through backpressure. Source ownership ends only on copy_ack. Postseal cancel cannot emit abort or permit an early restart; common reset is tested during partial source population and sealed destination copy.

New table configuration is AGE_LIMIT_MS=2000. Normal cases use the real road_time_snapshot millisecond generator. The separate explicitly controlled coherent-time group tests raw1996->upper2000 allowed and raw1997->upper2001 rejected, unknown sentinel, old-table retention without extra FPS count, and distinct source identities one controlled second apart. It does not measure real FPS. The real snapshot loss case stops only the time generator's source clock after a normal complete publication and waits for the actual destination watchdog to invalidate time.

Thirty actual-ROM cases include seven numerical streams under normal/random backpressure, real-to-empty consecutive results, original stage resets and ROM-owned cancel/reset drain, partial response error with automatic publisher abort, long output/meta/copy holds, postseal cancel, coherent age/identity updates, time loss, partial-source reset and sealed-copy reset. Endpoints are start acceptance, metadata acceptance, copy acknowledgement and next normal SOF active. Printed interval endpoints are disjoint; entry, metadata and copy waits are separately identified as contained counts.

The copy_ack timestamp is the source rising edge where the publisher samples the C8 acknowledgement pulse, so it measures publisher retirement rather than the earlier post-NBA first assertion of that pulse. Active is observed1ps after the destination update edge. These selected SOF phases yield acknowledgement before active; that order is not a global CDC guarantee. A copy finishing immediately before a SOF can become active before its acknowledgement returns to the source.

Start-driving decisions are sampled only on source rising edges. Diagnostic mode7 records actual accepted-cell counts and last-eight-cell identities; a cell-ready timeout fails immediately with frame, index and state details. These checks distinguish testbench admission mistakes from functional RTL faults.

The governed write-spec command rejects real empty ports (`modules[0].interfaces.ports must be non-empty`). The JSON intent contract and this manual companion are retained without adding false ports. This is a reported specification tooling limitation; actual simulator evidence and the strict eight gates remain separate.
