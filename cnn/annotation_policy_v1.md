# RoadYOLO 人工审核标注规则 v1

状态：审核工具的固定契约；不是已完成真值或正式验收。原始标签及历史评分不变。

## 类别与目标

- `person`：所有可明确辨认的人，包括静止、步行及骑行者。
- `vehicle`：car、bus、truck、bicycle、motorcycle；运动与静止均标。
- 骑行者的人体与车体分别标 person、vehicle，允许框重叠，不把人体作为车体的一部分。
- 无人停放的两轮车只标 vehicle，不能由 vehicle 标签推断必然有人。
- 部分遮挡但类别和可见范围可确定者仍标正例，记录遮挡；不凭想象补出隐藏肢体。
- 框紧包该目标的可见部分；被画面边界截断时裁到图边，记录截断。
- 不设按目标像素高度自动忽略的门槛。小目标只要能明确辨认就仍是正例。
- 确有目标但类别/范围无法可靠确认，或者真实内容不能确认的区域，标 ignore 并写原因；
  不能为了提高分数将困难但可辨认的人车改为 ignore。
- 不确定的审核结论保持草稿，不签署完整。来源类别不在两类范围或未定义者保留 ignore 待核，
  不能将来源 ignore 自动升级为背景或正例。

## 原图坐标

统一使用零起始、连续半开 XYXY：`[x1,y1,x2,y2)`，
`0 <= x1 < x2 <= 原图宽`，`0 <= y1 < y2 <= 原图高`。
是原始分辨率像素，不是网页缩放尺寸、720p 派生图或 512×288 网络坐标。
来源 XYWH 转成 `[x,y,x+w,y+h]`；VIRAT 闭区间最大坐标转成本契约时加 1。
界面拖框自动映射到原图坐标，有限小数允许保留；不静默裁正人工越界输入。
坐标修订不得自动继承旧 ROI 标签，历史完整帧验证标签仍保持原版。

## 审核动作

- A：接受已有来源框及类，保持原框和类不变。
- M：人工修改已有框或类别，必须给原因。
- N：人工新增目标框，必须核对 RAW、选择类及给原因。
- I：已有目标或新增区域设 ignore，必须给明确原因。
- D：删除确实错误或重复的已有标签，必须给原因；教师没响应不是删除依据。

教师提供低置信度疑点，不是最终真值。不能批量接受预测、自动补框、自动删框。
同类 IoU、错类重叠、教师未匹配都只是审核提示，不能当真值或整体误报率。
每张图先单独看 RAW，再看来源框及教师提示。逐项核对 person、vehicle、rider、
parked_vehicle、small_occluded、ignore；所有原始框须有明确动作。
仅人工填写 reviewer、确认 RAW 已查看、六项检查通过、所有原框均已处理后可签 complete。
文件导入器只能验证记录的一致性，不能证明人确实看过图片；不得生成虚假人工签署。

## 桶与版本

- `train_review`：固定 128 张目的性训练审核帧，来源仍是 train；全批审核通过才生成该子集的
  Verified GT。不得据此称全部 19,050 张训练图已经审核。
- `road_development`：已有 124 张地面开发审核图；不进入训练，按物理机位/原片家族核对隔离。
- `person_background_aux`：庭院 24 帧先保留 stress；如以后进入辅助训练，须重新冻结整个
  机位家族的划分，从验证/压力评分中排除，不能同源训练再宣称独立验证。
- 盲测预留仅记录元数据引用，本工具不枚举、不解码、不解析其标签。

Original → 人工 Patch → Verified 分别保存，原图、原始标签、来源和规则都用 SHA256 绑定。
修订生成新目录，不覆盖旧版。人工修订后的开发结果与历史结果分开报告。
系统性骑行者或静止车辆漏标须扩审相关训练家族，不能只修教师找到的几个例子。
没有全部完整真值及分组隔离证据，不启动正式 CNN 训练；正式 P95/R85、两轮类和 FPGA 规格不变。
